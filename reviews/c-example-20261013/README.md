# 해설 속 예문 반복 걷기 · 2026-10-13

영신: "있다 뜻의 be에서 해설에 예문이 반복돼 이런거 싹 없애자"

be ②의 해설은 "be는 ‘~이다’에 더해 ‘(~에) 있다’도 돼: I am at home. 나 집에 있어."였다. 뜻 줄과 예문(I want to be at home today.)이 이미 보여 주는 것을 예문 한 문장과 해석으로 한 번 더 읽힌다.

## 기준(Claude)

- **뺀다:** 해설 속 영어 예문이 카드 예문과 같은 쓰임을 다시 보여 주는 것. 예문만 빼고 남은 설명이 할 일을 하면 남기고, 남는 게 뜻 줄 되풀이뿐이면 해설을 비운다(be ②, available).
- **둔다:** 카드 예문에 없는 다른 쓰임·대비·관용 표현을 보여 주는 예문.
  - 대비: not의 I don't know, take의 Bring it here, cheap의 The price is low.
  - 다른 뜻: check의 Can I get the check?, funny의 That's funny!
  - 관용 표현: Don't mention it., What a shame!, How dare you!
  - 대답법: mind의 No, not at all.
- **둔다:** "take a shower 샤워하다"처럼 예문 속 덩어리 표현을 짚는 연어 표시. 문장을 다시 읽히지 않고, PRINCIPLES 4가 남기는 '함께 쓰는 말'이다(예문과 세 단어 이상 겹치는 해설 426장 대부분이 이것).

## 찾은 방법

- 해설에 영어 문장이 든 카드 115장과 짧은 영어 문장이 든 카드를 모두 읽었다.
- 해설과 예문이 세 단어 이상 겹치는 426장도 훑었다.
- 36장을 고쳤다(`edits.py`). 원장은 `c-example-20261013`이다.
- 50세트 run out of의 원본은 `pipeline/connections.json`이다(`pipeline/out/set50.json`은 조립이 만든다).
