## 안 A (검토 담당): 이솝을 이어 쓴 사람들
- 검토: 파이드(Phaedrus, 이솝 우화를 라틴어 운문으로 '다듬었다' — "이솝이 찾아낸 재료를 내가 다듬었다") — 겹침 0
- 검산: 바브리(Babrius, 같은 우화를 그리스어로 따로 지음. 따로 한 두 판이 맞으면 원형을 가늠) — 겹침 0
- 합치기: 캑스턴(William Caxton, 1484 영어 첫 이솝 우화집 인쇄, 여러 전승을 엮은 책; eggs/eyren 중 골라 찍은 고민) — 겹침 0

## 안 B (검산 담당): 이솝 우화를 이어받아 따지고 다시 다룬 사람들
- 검토: 벤틀리(Richard Bentley, 고전학자. 언어·연대 근거로 팔라리스 서한 위작을 밝히고 '이솝 우화' 모음이 이솝 글이 아님도 따짐) — 겹침 0 (자동차 상표와 같은 이름)
- 검산: 레싱(Lessing, 『우화론』: 교훈을 말하지 않아도 이야기만으로 하나의 답에 닿아야 한다 = 빈칸 하나의 답) — 낱말 겹침 0(blessing 부분 문자열 6)
- 합치기: 라퐁텐(La Fontaine, 이솝·파이드루스·필파이 등 흩어진 출처를 한 모음집으로) — 겹침 0

## 안 C (쓰기 담당 이솝): 알렉산드리아 문헌학자
- 검토: 트락스(Dionysius Thrax, 『문법술』에서 문법의 일 여섯: 읽기·비유·낱말과 사실 풀이·어원·유추·작품 판정 = 검토 점검표) — 겹침 0
- 검산: 제노도(Zenodotus, 도서관 초대 관장, 호메로스 첫 교정본. 사본을 맞대고 의심 줄엔 지우지 않고 표만 침. 이음이 셋 중 가장 느슨하다고 스스로 밝힘. CERN 자료 저장소 Zenodo와 같은 이름) — 겹침 0
- 합치기: 디디모(Didymus Chalcenterus, 앞선 학자들 주석을 모아 엮고 판본이 갈리면 어느 쪽인지 따져 적음. '청동 창자') — 겹침 0
- 뺀 이름: 아리스타르코스(GRE 예문에 동명 천문학자가 나옴)

# 2차 투표
- 검산(B 안): C 2, A 1. 짚음: 파이드 '다듬기'는 쓰기 쪽, 바브리는 본인이 두 판을 맞댄 게 아님, 캑스턴은 엮은 이가 슈타인회벨(옮긴 이). ※ eggs/eyren이 1484 『이솝』이 아니라는 지적은 A 안이 이미 1490 『Eneydos』로 맞게 적었으므로 B의 오독. 제노도 '지우지 않고 표만'은 틀림(줄을 빼기도 함), 트락스 작자 논란, 디디모 동명(장님 디디무스). 섞은 안: 벤틀리·레싱·캑스턴.
- 검토(A 안): B 2, C 1. 벤틀리 사실 맞음, 레싱 '하나의 답'은 원문(직관적으로 알아보게)보다 넓힌 해석이라 근거 문구 고치자, 라퐁텐이 캑스턴보다 합치기에 맞음(자기 안 약점 인정). 제노도 절반만 사실. 섞은 안 없음, B 그대로(예비: 검산 바브리).
- 쓰기(C 안, 이솝): B 2, A 1. 레싱 '하나의 답'은 해석이라 레싱 말처럼 적지 말 것, 라퐁텐은 다시 쓴 시인이라 쓰기와 색이 겹침. 섞은 안: 벤틀리·레싱·캑스턴(이음은 "옮겨 찍으며 골랐다"로).
- 합계: B 4, C 3, A 2. 섞은 안(벤틀리·레싱·캑스턴)은 검산·이솝 둘이 냄.
