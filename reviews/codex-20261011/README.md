0세트 개편과 Oxford 보강은 반영되어 있고, 1~45세트 조명 문법 전체 배치는 계획 단계가 남아 있다는 사실을 리뷰에 반영했다. 계획 미완료를 이미 완성된 기능의 회귀로 다루지 않는다. 표제어 입력·셔플·단어 순서를 유지하며 수능 어법 판단은 별도 마더텅 문법 교재에서 한다는 기존 합의도 유지한다.

## 근거를 찾는 법

- **각 차수의 review.json이 최종 종합 판단이다.** 분담 보고서는 근거이며 중복 합산하거나 초기 후보를 최종 확정 오류로 취급하지 않는다.
- 카드 번호 n과 현재 뜻·예문: [검수 당시 7,573장 고정본](full-review-20261011/cards.json). [전량 검토 범위](full-review-20261011/coverage.json), [검증 결과](full-review-20261011/verification.json).
- 실행 문제: [브라우저 확인](opus-review-20261011/browser-review.json), [축하 화면 겹침 캡처](opus-review-20261011/milestone-over-game.png), [과거 이어하기 확인](opus-review-20261011/set0-actual-history.json), [추가 기록 조사](opus-review-20261011/set0-historic-resumes.json).
- 문법: [기초](grammar-review-20261011/foundation.json), [실제 문형 목록·분포](grammar-review-20261011/distribution.json), [규칙 해설](grammar-review-20261011/rules.json).
- 보고서나 대화의 로컬 경로는 [경로 대응표](LINK_MAP.md)를 참고한다. 원문 보존을 위해 대화 안 링크를 고치지 않았다.
- HTML은 독립 문서다. GitHub에서 소스로 보이면 내려받아 브라우저에서 열면 된다. 모든 핵심 판단은 JSON과 대화 원문에도 있다.
- 첨부한 재현용 cjs는 당시 로컬 경로와 브라우저 환경을 사용한 기록이다. 현재 환경에 경로를 맞춘 뒤 사용해야 하며, 저장소 실행 코드에는 연결하지 않았다.

[MANIFEST.json](MANIFEST.json)에 범위·파일별 SHA-256·대화 메시지별 SHA-256을 남겼다. [전달 검증 결과](TRANSFER_VERIFICATION.json)도 함께 보관한다. 원래 로컬 검토 파일을 그대로 복사했으며 대화는 Codex 기록의 사용자 메시지와 사용자에게 표시된 답변·진행 안내만 추출했다. 이 폴더는 Git의 줄바꿈 자동 변환을 꺼 원문 바이트를 보존한다.
