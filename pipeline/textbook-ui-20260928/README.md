# 마더텅·EBS Fable UI 적용 · 2026-09-28

> 이 문서는 당시 UI 이식 기록이다. 이후 마더텅 PDF 발췌, EBS 발음 자료와 공통 발음 효과·단어 재생을 적용했다. 현재 기준은 [UI 표준](../../UI_STANDARD.md), 구현·배포 상태는 [최신 인수인계](../../HANDOFF.md)를 확인한다.

완성된 Fable 화면과 입력 표시를 두 교재 앱에 적용했다. Fable 파일 자체는 바꾸지 않았다. 마더텅의 한 exercise는 한 독해 지문에 대응하므로 분할·재배열하지 않는다. 본문 PDF가 도착하면 해당 지문의 실제 문장을 예문으로 옮기는 작업을 별도로 진행한다.

## 변경

- 같은 폭의 글자 칸에 답을 표시하고 정답을 별도로 크게 반복하지 않는다. 공백과 긴 표현의 줄바꿈을 유지한다.
- 첫 입력칸을 누르면 첫 글자만 한 번 열린다. 별도 힌트 버튼·글자 수 안내·키보드 입력 안내를 없앴다. 한 글자 답도 힌트만으로 제출되지 않는다.
- 고양이 대사는 시간 막대 자리에 나타난다. 두 줄 공간을 확보해 정답 전후 뜻과 글자 칸의 위치를 유지한다. 시간 막대는 연보라색에서 마지막 25%에 탁한 빨간색으로 바뀐다.
- 마더텅 발음기호는 입력 아래 문단에 이어 놓았다. 자동 발음과 기호를 눌러 다시 듣기를 유지한다. 기존 4,028개 발음 자료는 변경하지 않았다.
- 클리어 오답 카드의 장미·네 종류 꽃비, 확대된 본문 하트, 연속 퍼펙트 색과 울음소리를 적용했다. 콤보는 페이지 안에서만 유지된다.
- 마더텅 맨 위 제목과 2026/전체 선택은 유지한다. 상단 소리·기록 초기화 버튼은 없다. EBS는 기존대로 범위 선택이 없다.
- EBS에 별도 이어하기 키를 추가했다. 기존 완료·설정 키는 그대로이며 마더텅 기록과 섞이지 않는다.

두 교재 DATA 전체와 연습별 기록 주소가 기존과 일치한다. 단어·뜻·예문·순서·범위는 변경하지 않았다. 출제 순서·시간 제한·채점·오답 재학습·클리어 계산은 기존 교재 규칙을 유지한다. EBS에는 원래 검수된 발음 자료가 없으므로 이번 UI 작업으로 IPA나 추정 발음을 만들지 않았다.
