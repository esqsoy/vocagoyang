# 마더텅 원문 발췌

화면의 공통 기준은 [UI_STANDARD.md](../../UI_STANDARD.md), 현재 작업·배포 상태는 [HANDOFF.md](../../HANDOFF.md)를 따른다. 예문형·단어형을 구분하는 이 표시 방식은 2026-09-29 사용자 승인으로 전체 과정의 표준이 되었다.

사용자 제공 2027 마더텅 영어 독해 문제편의 각 지문을 해당 exercise에 연결한다. 기존 17단원·521개 exercise·6,498개 카드, 원본 DATA와 정답 판정은 유지한다.

`records.jsonl`은 카드별 검토 기록이다. 식별자는 `lesson/scope/ex/index`이며, 표제어 `term`은 원본 카드와 같아야 한다. `example`은 원문 발췌, `surface`는 그 안의 실제 어형, `translation`은 발췌 해석이다. 필요한 경우에만 `note`와 문맥상 뜻인 `contextMeaning`을 둔다. `sourceKind`는 본문·선택지·주석을 구분한다.

핵심 성분이 빈칸이거나 의도적으로 잘못된 어휘, 불명확한 인쇄문 등은 `hold`와 사유를 남긴다. 단독 선택지 어휘는 출처 확인 기록을 보존하되 의미 없는 예문 빈칸을 만들지 않는다. 이 두 경우는 기존 뜻-표제어 카드로 출제한다. 단어는 삭제하지 않는다.

예문 안의 해당 위치에 FABLE과 같은 표제어 입력칸을 둔다. 예문 아래에 별도 입력줄은 두지 않는다. 정답 입력과 오답 따라쓰기는 사전형 기준이며, 완료하면 문장 안의 원래 어형을 복원한다. 같은 단어가 반복되면 첫 위치에만 입력하고 나머지 위치는 함께 가린 뒤 복원한다. 서로 떨어진 세 구 표현은 두 부분 사이까지 하나의 입력 자리로 가리고, 공개 때 사이의 원문 표현도 복원한다. 판정과 발음은 원래 표제어 기준이다. 원문 철자가 표제어와 다른 경우 IPA는 전체 단어 단위로 표시해 잘못된 글자별 대응을 피한다. 뜻을 문맥에 맞게 보완해도 동형이의어의 발음 조회는 기존 뜻을 함께 참조한다.

별도 발음기호/해설 상자는 표시하지 않는다. 필수 해설 `note`는 고양이 대사에 우선 표시하고, 문제 단계부터 같은 높이를 예약해 정답 공개 때 내용이 밀리지 않게 한다. 해석은 예문 아래에 유지한다. 정답 또는 따라쓰기 완료 후 입력칸의 정답과 예문 속 강조 단어를 누르면 표제어의 음성과 발음 효과가 함께 재생된다. 키보드 Enter/Space로도 재생하며 점수나 하트를 다시 발생시키지 않는다.

정답 공개 시간은 해석·주석 분량에 따라 1.2~6.5초, 두 번째 회독부터는 최대 3.5초다. 음성 완료 대기는 유지한다. 기존 카드 터치/Enter로 즉시 넘어갈 수 있다. 답을 입력하는 제한 시간은 바꾸지 않는다.

수정 후 실행:

```text
node pipeline/mother-tongue-excerpts/build.cjs
node pipeline/mother-tongue-excerpts/build.cjs --check
node pipeline/test-mother-tongue-excerpts.cjs
node pipeline/test-mother-tongue-layout.cjs
node pipeline/test-mother-tongue-pronunciation.cjs
```

생성기는 표제어/개수/중복/출처 어형을 검증하고 HTML의 표시된 데이터·CSS·런타임 구간만 갱신한다. 원문 PDF와 전체 OCR은 저장소에 포함하지 않는다. 자동 검사는 사람이 읽어 작성한 발췌를 검증하는 보조 수단이며, 문맥 검수를 대신하지 않는다.

실행 시 인덱스의 단어 수도 [공통 집계기](../README.md#인덱스-단어-수-자동-갱신)로 갱신한다. `--check`에서는 인덱스의 수치가 오래됐는지도 확인하며 파일을 수정하지 않는다.
