# Fable 강세 해설 정리 · 2026-09-27

2026-09-27 배포 변경에 포함. 배포 범위는 [DEPLOYMENT.md](../../DEPLOYMENT.md)에 기록한다.

총 63개 카드(원본 61개, 연결된 복습 카드 2개)의 해설을 수정했다. 전체 6,859카드의 뜻·예문·발음기호·순서와 UI는 유지했다.

## 편집 원칙

- 단순 강세 위치의 재설명은 “강세 주의.”로 줄인다. 이전 정리에서 없앴던 안내 중 26개도 이 형태로 되살렸다.
- 품사·의미에 따른 강세 차이는 남기고, 한글 독음·발음기호·대문자로 같은 발음을 되풀이한 부분은 줄인다.
- thirteen/thirty 같은 혼동 대조와 접사에 따른 강세 이동 설명은 유지한다.
- contract는 동사 전체를 일반화하지 않고 계약(서)/수축하다라는 뜻으로 대조한다.
- ally, finance, protester, fragment는 가능한 발음 변이를 명시한다.

## 검증

기존 내용·진도 관련 검사 3종 통과. 63개 해설 외 모든 데이터와 UI가 이전 상태와 동일하다. HTTP 응답으로 로컬 미리보기 반영을 확인했다.
