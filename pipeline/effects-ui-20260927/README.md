# Fable 장미·하트와 연습 간 퍼펙트 콤보

2026-09-27 운영자가 로컬 시험판을 승인하고 공개 반영을 요청했다. 게임 코드의 원본은 ../../vocagoyangfable.html이며 아래 파일은 이번 변경의 편집 원본을 보관한다.

## 승인된 효과

- 본문 정답 하트: 크기 .94 → 1.13(약 20% 확대), 시간 배율 1 → .92(8% 단축). 기존 콤보별 겹 수와 발생 시점은 같다.
- 클리어 후 오답 카드 터치: 중앙에 옆모습의 빨간 장미 한 송이. S자 줄기와 교차하는 잎. 장미는 104×176px, .82초다.
- 주변은 꽃다발/포물선 꽃비/벌어지는 꽃잎/빛과 꽃가루의 네 가지 기존 효과를 터치마다 순환한다. 꽃 18/18/18/16개, 확산 거리 배율 1.6/1.45/1.75/1.5. 광원과 꽃가루도 늘렸으며 횟수에 따라 입자 수가 무제한 늘어나지는 않는다.
- 각 터치 효과는 독립적으로 1.3초 후 제거된다. 카드 삭제·발음·다음 연습 이동 동작은 유지한다. 동작 줄이기 설정에서는 중앙 장미의 짧은 페이드만 사용한다.
- SVG는 HTML 안에 포함돼 별도 네트워크 요청이 없다. rose-effects.cjs가 review-rose.svg를 읽어 이전 공개 HTML에 한 번 적용하는 변환이다. 이미 적용된 HTML에는 재실행하지 않는다.

## 연습 간 퍼펙트 콤보

기존 조건인 전체 연습·오답 0·첫 시도 100%를 유지한다. 1연속은 금빛 PERFECT와 냐아아아옹—!!, 이후 PERFECT ×N과 아 한 글자를 매번 추가한다. 색은 금빛→분홍→하늘색→연보라→민트로 순환한다. 2.2초 또는 터치로 닫힌다.

목록/세트를 거쳐 다음 연습을 선택해도 이어진다. 퍼펙트가 아닌 전체 연습을 완료하거나 진행 중인 연습을 포기하면 초기화한다. 부분 복습은 콤보를 올리거나 끊지 않는다. 새로고침하면 초기화되며 저장 기록의 스키마는 바꾸지 않는다. 전체 과정 완료 시 기존 엔딩을 우선한다. 변환 원본은 perfect-combo.cjs다.

## 검증과 배포 범위

- 실제 브라우저에서 네 가지 꽃비, 5회 연속 터치 순서 1·2·3·4·1, 카드 삭제, 효과 래퍼 정리를 확인했다. 넓어진 판에서는 꽃 수 18/18/18/16과 중앙 장미 1개를 확인했다.
- 퍼펙트 2연속 화면의 분홍빛, PERFECT ×2 및 아 4개를 확인했다.
- 검사 8종 전부 통과: reading-core, keyboard, spacing, session, morphology-content, connections-content, connections-input, pool-expansion.
- 7,344회 모의 플레이와 결합 표현 1,336 입력 경로가 통과했다. reading-core에는 목록 이동·완료 중복 호출·부분 복습·오답·중도 종료·재시작·첫 정답률의 콤보 검사를 추가했다.
- DATA/READING_CORE/MORPHOLOGY/CONNECTIONS는 직전 공개판과 동일하다. 51세트/612연습/6,876카드, 기존 완료/이어하기 기록을 유지한다. 마더텅·EBS·교재 선택 페이지는 수정하지 않았다.
- 체험용 /fixture 화면, 버튼과 정지 프레임 기능은 배포하지 않는다.
- 되돌리기 기준: 1f1e947198cb99d56ac424d85925f298bb2ef883.

## 후속 디자인 과제

운영자가 제공한 두 인물이 장미에 물을 주는 '장미의 탄생' 참고 이미지는 향후 본문 클리어 효과를 위한 별도 디자인 과제다. 조개·물결·양옆 물방울이 꽃잎으로 이어지는 새 연출은 이번 배포에 구현하지 않았다. 현재 승인된 장미 디자인을 기준으로 천천히 발전시킨다.
