## 해석(Claude, 영신 검토 전)

- **규모를 묶는 것은 PRINCIPLES 2-4다(빈칸 단어가 지식의 축).** 지식이 자연스럽게 걸리는 단어는 네 갈래다.
  - 사물·개념의 이름: empire, treaty, vaccine
  - 이름의 일부가 되는 형용사: French Revolution, Soviet Union
  - 날짜가 되는 서수·달
  - 경구 속 단어
  - 동사·기능어·생활어에 지식을 얹으면 "Americans experienced poverty"형 문장이 된다. 그래서 현실적인 교체는 250~300장이다. 기존 284장과 합치면 약 550장으로, 12장에 1장꼴(연습 한 판에 한 번꼴)이다.
- **카드마다 따로 고르면 생기는 문제**(R 목록에서 실제로 보인 것):
  - 같은 사실이 몰린다: 프랑스혁명 5장, 산업혁명 6장, 2차 대전·홀로코스트 8장, 냉전 4장.
  - 20세기 전쟁으로 쏠린다.
  - 기본어에 무거운 내용이 얹힌다(0세트 million에 홀로코스트).
  - 빈 곳이 생긴다: 르네상스·계몽·아시아·아프리카·라틴아메리카, 과학사.
  - → 지식 뼈대(노드 목록)를 먼저 설계하고 단어를 거는 순서를 제안한다. 단어가 난도 순이라, 앞 세트에는 날짜·사건, 뒤 세트에는 개념·해석이 걸리는 나선형이 자연스럽게 나온다.
