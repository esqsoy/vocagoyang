# 모아둔 카드와 단어 검색

FABLE·마더텅·EBS 공통 개인 복습 기능이다. 현재 기기·브라우저의 각 과정별 저장 공간을 사용한다. 공개 배포 상태는 HANDOFF를 따른다.

- 문제·정답 공개·따라쓰기 중 고양이를 누르면 현재 카드 저장/해제를 전환한다. 담은 뒤에만 고양이 목 왼쪽(고양이 칸 안)에 하트(♥)를 띄우고(담기 전에는 표시 없음, 26.10.08 영신), 접근성 레이블로도 상태를 알린다. 홈의 ‘♥ 모아둔 카드’와 검색의 ‘♥ 담김’도 같은 하트를 쓴다. 저장 터치는 제출·다음 진행으로 전파되지 않는다. 공개 후 저장하면 자동 진행 대기를 다시 시작해 조작 피드백을 볼 시간을 둔다.
- 홈의 번호 없는 ‘모아둔 카드’에서 짧은 연습으로 다시 플레이한다. 같은 표제어의 모아둔 카드들은 같은 연습에 두며 한 묶음이 12장을 넘으면 표제어 보존을 우선한다.
- 목록에서 예문·해석·해설을 펼치거나 개별 카드를 뺄 수 있다. ‘목록 복사’는 과정·단어·뜻·원래 위치·예문·해석·해설을 텍스트로 복사한다. Clipboard API를 사용할 수 없으면 선택 가능한 텍스트 상자를 제공한다.
- 기존 번호 세트, 클리어율, 정규 이어하기, 엔딩과 연속 퍼펙트 콤보에 포함하지 않는다. 개인 복습을 완료해도 카드는 자동 삭제되지 않는다. 플레이 중 해제는 저장 목록만 바꾸고 진행 중인 카드·큐는 그대로 둔다.

## 홈 검색 · 2026-10-06

세 과정 홈에 `단어·뜻 검색`을 둔다. 영어 표제어와 표시형(`word`, `term`), 한국어 뜻과 마더텅의 원래 뜻(`meaning`, `originalMeaning`)을 검색한다. 예문·해설에만 언급된 단어까지 검색하지 않으며 동의어 판정용 ALT를 검색 별칭으로 사용하지 않는다. 마더텅 검색은 현재 출제 연도 선택과 관계없이 이전 기출을 포함한 전체 카탈로그를 대상으로 한다.

NFKC·대소문자·공백·아포스트로피·하이픈을 정규화한다. 정확 일치 → 앞부분 일치 → 포함 → 공백/하이픈/아포스트로피를 뺀 정확 일치 → 뜻 포함 순서이며 같은 순위는 원래 카드 순서다. 빈 입력/기호만 입력에는 전체 카드를 나열하지 않는다. 한 글자 검색은 허용한다. 기존 메모리 카탈로그를 첫 검색 때만 인덱싱하고 결과 DOM은 24장씩 추가한다. 외부 요청이나 새 라이브러리는 없다.

결과의 별 버튼은 기존 저장 ID와 저장 기능을 그대로 사용한다. 카드별 뜻·복습 위치를 합치지 않으며 상세는 원문/해석/해설을 현재 자료에서 가져온다. 마더텅의 원래 뜻과 문맥 뜻이 다르면 상세에 원래 뜻도 표시한다. 저장 변경과 다른 탭의 storage 이벤트는 버튼과 개수만 갱신해 입력·상세 펼침·스크롤을 보존한다. 홈에 다시 돌아오면 검색어를 유지하되 새로고침하면 빈 입력으로 시작한다. 한글 IME 조합 중에는 검색을 미루고 일반 입력에는 120ms 지연을 둔다.

## 원본과 연결

`runtime.js`와 `style.css`가 공통 원본이며 `node pipeline/saved-cards/build.cjs`로 세 HTML에 삽입한다. 검사 모드는 `--check`다. 기존 게임 연결 지점은 세 HTML 생성 구간 밖에 있고 최초 변경은 `host-hooks.json`에 기록했다. 이 연결 지점은 빌더가 다시 생성하지 않는다.

저장 키는 각 과정 `STORAGE + '-saved-cards-v1'`. 저장 자료는 `{id, addedAt}` 배열이다. 카드 문구의 사본을 저장하지 않으므로 같은 ID의 예문·해설 수정은 다음 로딩부터 반영된다. FABLE ID는 원래 연습의 기록 키·표제어·뜻 번호·어원/표현 식별자로 만든다. 세트 이동 후에도 기존 기록 키를 유지하면 같은 카드로 연결된다. 마더텅/EBS는 단원·범위·연습·원본 카드 인덱스를 쓰므로, 향후 원본 카드 순서를 바꿀 때는 저장 카드 이행도 검토해야 한다. 원문 발췌를 연결한 뒤 카탈로그를 만들어 마더텅 context와 originalMeaning을 보존한다.

개인 세트는 `state.savedLesson`에만 두고 정규 `state.lessons`와 DATA에 넣지 않는다. 삭제 중 실행 큐를 바꾸지 않도록 목록으로 돌아왔을 때 연습을 다시 구성한다. 저장 공간이 거부되면 성공으로 표시하지 않는다. 카드 상세는 텍스트로 삽입한다.

2026-10-03 승인한 부분 이동·재구성에는 카드별 `savedId`를 명시해 이전 원본 위치 기준 ID를 우선 사용한다. 원래 묶음이 여러 새 연습으로 재편되더라도 같은 카드로 이어진다. `placement-regrouping.test.cjs`에서 전체 7,067개 이전 ID와 실제 저장 목록 재로딩을 확인한다.

## 검증

`node pipeline/tests/card-search.test.cjs`는 세 과정의 영어/한글 검색·순위·공백/하이픈 생략·기호 입력·24개씩 더 보기·뜻별 카드 구별·저장/해제/새로고침/실패·다른 탭 저장 동기화·IME·정규 기록 보존·텍스트 안전성을 확인한다. 마더텅 원래 뜻으로 검색한 결과의 표시와 이전 기출을 저장해 개인 복습으로 재생하는 경우도 검사한다. 2026-10-06 내장 브라우저에서 FABLE 영어/한국어 검색→담기→목록→개인 복습, 마더텅 원래 뜻과 원문 표시, EBS 검색을 확인했다. 390/320px 화면에서 상세가 전체 카드 너비를 쓰도록 보완했다. 확인용 카드만 개별 해제했다. 실제 iPhone Safari 검사는 아니다.

`node pipeline/tests/saved-cards.test.cjs`는 세 과정 전체 ID 고유성(7,067/6,498/597), 저장·해제·재로딩·저장 실패·손상 자료, 질문/공개/따라쓰기 중 클릭·키보드, 개인 복습의 정규 기록·콤보·엔딩 분리, 플레이 중 해제, 원문·발음 연결, 동일 표제어의 별도 카드와 저장 출력의 안전성을 확인한다. 교재의 역사적 함수 해시는 `restore-host.cjs`로 기록된 개인 복습 분기만 되돌려 비교하며 고정 기준을 갱신하지 않는다.

2026-10-03 좁은 내장 브라우저 화면에서 세 과정의 저장→목록→재플레이→정답→개인 복습 완료를 확인했다. FABLE April의 재로딩 후 보관, 원문/해석/해설 펼치기와 복사 성공, 마더텅 official의 원문 Officials 복원, EBS universality의 독립 입력과 정답 공개를 확인했다. 세 과정 정규 진도는 0으로 유지됐고 경고·오류 로그가 없었다. 검증용 저장 카드는 개별 해제했으며 저장 기록 초기화를 사용하지 않았다. 실제 iPhone Safari 검사는 아니다.
