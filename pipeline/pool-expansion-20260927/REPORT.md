# FABLE 승인된 어휘 풀 보완 · 2026-09-27

운영자의 “모든 제안에 찬성함 실행해주고 업뎃도 해줘” 승인을 반영했다. 전수 내용 검수 직후의 6,861카드를 기준으로 17카드를 추가하고 중복 2카드를 통합했다. 현재 51세트·612연습·6,876카드이며 원본 520묶음과 한 연습 4~15카드 범위를 유지한다.

새 독립 표제어 6개에 7카드, 기존 표제어의 뜻 보충 5카드, 결합 표현 5카드다. 이 수치는 새 어족 17개를 뜻하지 않는다. given은 give의 가족이며 나머지 기존 뜻·구 표현도 별도 어족으로 단순 합산하지 않는다.

## 중복과 기존 카드 정리

- 20세트의 tyre 카드를 17세트 tire 명사 카드로 통합했다. 미국식 tire·영국식 tyre 설명과 tyre 입력 인정은 유지된다. tire 동사에는 tyre를 정답으로 인정하지 않는다.
- 34세트의 법적 절차 proceedings 카드를 41세트 proceeding으로 통합했다. 법적 절차와 행사 진행의 두 뜻은 그대로다. 예문의 빈칸 뒤에 s를 제공해 실제 복수형 proceedings를 보여 준다. 행사·회의 기록의 뜻은 복수형으로 쓴다는 설명을 보완했다.
- tempt의 능동·수동 문형 두 카드는 유지했다.
- bill의 기존 “지폐 / 법안” 뜻을 지폐로 좁히고 법안은 별도 세 번째 카드에서 의회의 표결 예문으로 가르친다.
- 새 카드의 허용 답은 necessary(essential의 필수 의미), provide(furnish), so long as(as long as)의 3개만 더했다. 모두 실제 문맥과 뜻이 맞고 입력 글자 수가 같은 대체 표현이다.

## 앞선 전수 검수도 함께 배포

[전체 내용 검수](../content-review-20260927/REPORT.md)의 원본 174카드·193필드, 복습 복제까지 175카드·195필드 교정을 포함한다. 예문 20·해설 142·뜻 11·번역 18·고양이 대사 4필드이며, 그리스어·라틴어·고대영어 어원을 보완한 대표 카드 43장도 포함한다. 이 수치는 이번 확장 카드 수와 별개의 작업 내역이다.

## 검증과 복원

검사 8종 모두 통과했다. 기존 모의 플레이 7,344회와 결합 표현 입력 1,336경로를 유지하고, 신규 카드·공백 입력·허용 답·변경 그룹의 완료 기록을 추가로 검사했다. 상세 결과는 validation.json에 있다.

findings.json에는 추가·삭제 카드, 기존 필드 수정, 변경 원본 묶음의 전체 전후 값을 기록했다. 변경 묶음을 되돌리면 확장 직전 DATA SHA-256 9a25a4b1ca7b344c2b77223c7c5486a975c7eadae4bcdb626847c2ef0e6ae6c7과 일치한다. 기존 역사적 검수·기록 fixtures도 그대로 복원해 확인한다.

HTML의 DATA 외 코드·스타일·다른 상수는 확장 직전과 같다. 기존 승인 UI와 게임 방식을 유지했다. 마더텅·EBS·교재 선택 파일은 변경하지 않았다.

전체 내용 검수 직전의 공개 기준은 7f38a095f1556dc6f2a4b506e8d1bbcc72dacacd, 풀 확장 직전의 로컬 검수 커밋은 eb1e621이다. 실제 공개 완료 여부는 배포 후 GitHub Pages 결과와 공개 파일의 SHA-256을 비교해 확인한다.
