# FABLE 어원 과정 보강 결과

완료: 2026-10-01 KST. 사용자가 2026-09-30 제안한 신규 표제어 37개를 모두 승인했다. **로컬 반영·검증 완료, 커밋·공개 배포 전**이다.

## 실제 구성

| 범위 | 이전 | 현재 |

| FABLE 전체 | 6,876카드 / 612연습 | 7,036카드 / 618연습 |

기존 167카드는 전부 유지했다. 기존 풀에 있던 표제어의 복습 123카드와 새 표제어 37카드를 추가했다. 327은 카드 수이며, 새 표제어가 160개라는 뜻이 아니다. 기존 33카드는 해설만 보완했다. 다른 과정의 표제어를 옮기거나 삭제하지 않았다.

47은 9~11카드, 48은 8~13카드로 묶었다. 32연습 중 29개는 9~11카드, 2개는 8카드, 1개는 13카드다. 단위 내부의 어근 가족과 직접 대비쌍을 분할하지 않는다. 모든 어휘가 서로 같은 어원이라는 뜻은 아니며, 언어별로 같은 의미를 나타내는 서로 다른 어근도 비교한다.

## 설계와 내용

- micro/macro, inter/intra, homo/hetero, symmetry/asymmetry, harmful/harmless 등의 연결을 완성했다.
- 하나·둘·여럿 → 도형 → 달 이름 → 십·백·천 → 절반·측정 단위로 숫자 요소를 연결했다.
- 움직임·결합·지각·말하기·판단·생명·사회·시간·과학 어근을 기존 어휘 중심으로 보충했다.
- monopoly의 -poly는 팔다 계열이며 poly-(많은)가 아니다. diameter의 dia-는 2가 아니다. 라틴어 centum/mille와 SI의 centi-/milli- 배수는 구별했다.
- manufacture는 기계 생산에도 쓰고, evolve가 반드시 더 좋아짐을 뜻하지 않는다는 점을 예문·해설에 반영했다.
- 그리스 원문·로마자 전사는 대표 해설과 메타데이터에 기록했다. 현대 영어 발음은 단어를 눌러 기존 음성·IPA 효과로 확인한다. 결합형마다 가짜 고정 발음을 만들지 않았다.
- 추가 예문은 모두 10단어 이내, 어원 카드 해설은 모두 70자 이내다. 예문·번역·해설은 직접 작성했다. 교재의 연습 문제나 예문을 복제하지 않았다.

학습서의 실제 확인 범위와 개별 근거는 [SOURCES.md](SOURCES.md)에 있다. 정량 빈도 순위나 독해율 실측에 근거한 최적화라고 주장하지 않는다.

## 진도와 유지 범위

47·48은 내용·경계를 재구성했으므로 새 진도키 `morphology-47-20260930`, `morphology-48-20260930`을 사용한다. 예전 완료 기록은 저장소에서 삭제하지 않지만 새 연습을 자동 완료시키지 않는다. 이전 두 세트의 이어하기 위치도 새 경계와 맞지 않으면 기존 앱의 첫 미완료 탐색으로 돌아간다. 다른 49개 세트의 데이터·진도키·이어하기는 그대로다.

게임 방식·UI·음성 선택·속도·하트·장미 효과·정답 허용 정책은 바꾸지 않았다. IPA 지도만 현재 카드에 맞춰 다시 생성했다. 마더텅·EBS 파일의 내용은 변경되지 않았다. 이전에 수정한 0세트 September~December 해설도 보존했다.

## 이어서 수정하기

현재 원본은 `pipeline/morphology.json`이다. 이후 수정은 원본을 고치고 `python pipeline/assemble.py`, `node pipeline/ipa-effects/build.cjs` 순서로 반영한다.

이 폴더는 이번 변경의 근거·보존 원장이다. `before-morphology.json`, `before-lessons.json`은 확장 전 스냅샷, `findings.json`은 정확한 변경과 전체 DATA 해시, `restore.cjs`는 과거 검사의 역변환이다. 이미 적용된 `build-proposal.py`를 다시 실행해 기준을 덮어쓰지 못하게 막았다. `apply.py`는 이번 저작 자료를 재현하는 도구이며 **향후 독립적으로 수정한 원본 위에 재실행하지 않는다**.

`cards.txt`와 `unit-history.txt`는 이번에 작성한 추가 자료다. 초기 16개 카드 샘플은 `card-drafts.json`에 역사적 초안으로만 남는다. 실제 확정 내용은 원본과 `findings.json`을 따른다.
