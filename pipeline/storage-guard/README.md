# 저장 키 검사기(storage-guard)

esqsoy.github.io에 올라가는 게임들은 주소가 같아서 브라우저 저장 공간(localStorage)을 함께 쓴다. 한 게임이 남의 키를 쓰거나 저장 공간을 통째로 지우면 다른 게임의 학생 기록이 섞이거나 사라진다. 고양 시리즈가 열 개를 넘을 것이라 약속만으로는 막기 어렵다. 그래서 장부와 검사기를 둔다.

- 결정: 26.11.13 Claude. 영신이 "열개이상의 고양이 만들어질거니까 문제생길여지도 없앨 궁리를 해보자"고 했다. Claude가 안을 냈고, 영신이 "나머지는 네 판단에 맡길게"라고 했다. 원칙은 [PRINCIPLES 0](../../PRINCIPLES.md#0-목적).
- 26.11.12 확인 결과, 같은 주소의 일곱 게임은 모두 자기 앞머리를 쓰고 있어서 겹치는 키가 없다. 아래 검사도 일곱 게임 모두 통과했다(분가는 읽기 전용 사본으로 돌렸다).

## 규칙

1. **앞머리 = 저장소 이름 + `-`.** 모든 저장 키는 자기 앞머리로 시작한다. 보카고양만 예외로 `goyang-`이다. 첫 게임이었고, 바꾸면 학생 기록이 사라진다.
2. **새 게임은 장부(`registry.json`)에 먼저 올린다.** 앞머리가 다른 게임 앞머리로 시작하면 안 된다. 예를 들어 `goyang-common`이라는 저장소를 만들면 그 키가 `goyang-`으로 시작해서, 보카고양 기록 옮기기가 그 키까지 집는다. 저장소 이름을 정할 때 장부를 본다.
3. **저장 공간을 통째로 다루지 않는다.** 다음을 쓰지 않는다.
   - `localStorage.clear()`
   - sessionStorage
   - IndexedDB
   - 서비스 워커
   - 쿠키 쓰기
   
   전체 키를 도는 코드는 자기 앞머리만 골라서 읽는다(기록 옮기기처럼).

## 파일

| 파일 | 무엇 | 같이 쓰나 |
|---|---|---|
| `registry.json` | 앞머리 장부(게임, 저장소, 앞머리) | 같이 쓴다. 본가가 고치고 분가는 가져간다 |
| `check.cjs` | 검사기. 장부 검사와 대상 HTML 검사 | 같이 쓴다 |
| `test.cjs` | 규칙 검사(지어낸 예)와 이 저장소 페이지 검사 | 같이 쓴다 |
| `config.json` | 이 게임 이름(`game`), 볼 HTML(`targets`) | 게임마다 다르다 |

## 검사기가 보는 것

- 장부: 앞머리 꼴(소문자, `-` 또는 `_`로 끝남). 앞머리끼리 앞부분이 겹치지 않는지.
- 대상 HTML:
  - 위 금지 목록.
  - `localStorage.getItem/setItem/removeItem`에 글자 그대로 넘긴 키가 자기 앞머리로 시작하는지.
  - 다른 게임 앞머리로 시작하는 글자가 있는지. 본가 코드를 가져오면서 `goyang-` 키를 그대로 둔 것을 잡는다.
- `/* */` 주석 속 언급은 키로 보지 않는다.
- 변수로 조립한 키는 다 볼 수 없다. 조립에 쓰는 앞부분 글자(`'goyang-pace-'`)까지는 본다.

`node pipeline/storage-guard/check.cjs`(`--json`), `node pipeline/storage-guard/test.cjs`.

## 저장 공간 크기 (26.11.13 판단: 지금은 손대지 않음)

- 한 주소의 저장 공간은 브라우저마다 약 5MB이고, 모든 게임이 나눠 쓴다. iPhone Safari 기준으로 글자 약 260만 자로 잡는다.
- 보카고양 세 교재를 끝까지 다 하면 약 29만 자다(26.11.12, 세 교재 DATA로 셈). 가장 큰 것은 익힌 단어 목록(약 11.7만 자)과 진행 속도 600판(교재마다 약 2.8만 자)이다.
- 지금은 손대지 않는다. 학생 대부분은 게임 한두 개를 한다. 그리고 저장 형식을 바꾸면 기록 옮기기 파일의 옛 형식과도 맞춰야 한다.
- **다시 볼 때:**
  - 같은 주소에서 저장하는 게임이 8개를 넘을 때
  - 한 게임의 다 했을 때 크기가 30만 자를 넘을 때
  - 기록이 저장되지 않는다는 제보가 올 때
  
  그때는 익힌 단어 목록을 줄이고, 저장이 실패하면 고양이가 알리게 한다.
