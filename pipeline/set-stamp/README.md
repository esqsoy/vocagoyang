# 세트 완주 도장 · FABLE 엔딩 · 2026-10-14

영신 요청: "set별 완주시 뭔가 있어야 하지 않겠어? 그리고 fable 엔딩". 원리는 [PRINCIPLES 15절](../../PRINCIPLES.md#15-세트-완주-도장과-fable-엔딩), 화면은 [UI_STANDARD](../../UI_STANDARD.md#세트-완주-도장과-fable-엔딩--2026-10-14).

## 파일

- `runtime.js`, `style.css`: FABLE HTML의 `/* SET_STAMP_START */ … /* SET_STAMP_END */`와 `<style id="set-stamp-style">`에 들어간다.
- `build.cjs`: 넣기. `--check`는 HTML이 원본과 같은지만 본다. 진행 속도(`pipeline/pace`) 블록 뒤, 마지막 `renderHome();` 앞에 넣는다(감싸기 순서: 도장 → 속도 → 돌파 축하 → 본래 finishExercise).
- 테스트: `pipeline/tests/set-stamp.test.cjs`.

## 게임 코드(FABLE HTML, 손으로 쓴 부분)와 나눈 일

- 게임 코드: `setPassed`(클리어 + 도장, 모듈이 없으면 클리어만)로 세트를 연다. 잠금 칸 문구, 세트 칸의 `data-lid`, 결과 화면 '다음' 버튼 계산(`setSumNext`), 세트 대사(`LESSONCLEAR`), 엔딩은 처음 다 끝낸 판에서만 예약, `showEnding()`은 `feShow()`를 부른다.
- 모듈: 도장 기록, 복습 목록, 도장 화면, 홈 장식, 엔딩 장면, 감싸기(finishExercise·showEnding·renderHome·show), 키보드.

## 저장

- `goyang-fable-stamps-v1` = `{세트 id: 도장 찍은 시각(ms)}`. 0은 업데이트 전에 이미 끝낸 세트(날짜 없음).
- 처음 열 때 키가 없으면 그때 다 끝나 있는 세트를 0으로 적는다. 키가 있으면 건드리지 않는다.
- 복습 목록은 `goyang-missed-words-v1`(돌파 축하의 틀렸던 단어 기록)을 읽는다. 따로 적지 않는다.

## 순서

포효(2.2초) → 돌파 축하 → 복습(학생이 누름) → 도장 → 엔딩. 도장은 포효·돌파 축하가 닫힐 때까지 기다린다. 판이 새로 시작되면 도장은 홈의 '도장 받기'로 넘긴다. 엔딩 예약은 도장이 끝날 때까지 미룬다.

## 엔딩 산

- `feWorld`: 세트마다 고유 표제어를 7px 글자로 재고, 세트가 글자량만큼 산 넓이를 가져가게 층 경계를 정한다(층마다 글자 크기가 같게). 산등성이는 좌우 폭을 따로 잰다.
- `feBuild`(26.10.15 단어의 주마등): 산 전체를 호수 위 전경 배율로 고정하고, 모든 단어(`seq`, 배운 순서)를 하나씩 가운데 크게 띄웠다가 제자리로 날려 큰 산 캔버스(`world`, 최대 4096px)에 칠한다. 무대 크기 사본(`mini`)은 바뀐 사각형만 다시 옮긴다.
  - 시간표: 속도 `r(t)=r0·e^(-t/τ)`. 끝 속도 `rEnd`=초당 8단어와 전체 시간 `T`(전체 60초, B1 30초)로 `rEnd·τ·(e^(T/τ)-1)=단어 수`를 이분법으로 풀고, k번째 단어 시각은 `-τ·ln(1-k/(r0·τ))`. `feState.feSpeed`에 N·T·τ·r0를 남긴다(검사용).
  - 불꽃: `.fe-bg`(산·대사 뒤, lighter 합성)에 로켓과 모양(`burst`: 전통 kiku·botan·yae(八重芯)·goju(五重芯급, 동심원 다섯 겹)·willow, 그 밖 rose·flower·peony·ring·crossette), 일제 사격(`salvo`), 같은 자리 두 번 터짐(`dbl` → `later`), 수면 반사. 전통 불꽃은 `sph`(피보나치 구를 화면에 비춤)로 꽉 찬 원을, 芯은 `ring`으로 또렷한 동심원을 만든다. 터진 직후 0.18초는 밝기를 제곱으로 올려 알갱이가 한 점에서 흰 덩어리가 되지 않게 한다. `.fe-fx`(앞, 보통 합성)에는 금빛 반짝임만, 비어 있으면 지우지도 않는다. 불꽃 판은 해상도 1.25배까지. 알갱이는 색별 빛 방울 그림을 찍고 꼬리는 색·밝기별로 묶어 긋는다. 알갱이 옵션: `dr`(감속), `tl`(꼬리 길이), `c2/ct`(색 바뀜), `strobe`(깜빡임), `split`(넷으로 갈라짐).
  - 화질 조절 `Q`: 프레임 시간 평균이 21ms를 넘거나 알갱이가 6,500개를 넘으면 새 불꽃 알갱이 수를 줄이고(최저 0.35), 여유가 생기면 되돌린다. 9,000개를 넘으면 새로 터뜨리지 않는다. `feState.fxStat()`이 알갱이 수와 Q를, `feState.fxLock(q)`가 Q 고정을, `feState.fxFire(kind,pal)`가 가운데 한 발을 쏜다(검사용: 헤드리스는 느려 Q가 내려가므로 폰 화질을 보려면 1로 고정).
  - 다 쌓이면 피날레 열두 발, 깃발, 금빛 이름표 2.4초. 배지·큰 도장 화면에서도 불꽃은 화면 아래에서 계속 올라온다.
- 미리보기 주소는 `hashchange`에서도 읽고, 띄운 뒤 주소의 #을 지운다. 대소문자는 가리지 않는다.
- B1은 25세트 층까지만 그리고 위를 점선으로 남긴다.
- 드론 쇼: `FE_LINES` 각 줄의 다섯째 칸이 드론 명령(up·bigmt·ilsan·cat:표정·ieung·panic·study1 / B1 outline·question·study1, land는 남겨 둠)이고 `feNext`가 `feState.drone(cmd)`로 넘긴다. 드론 650대(`DN`, 고양이 SVG 칸 수)는 무대 기준 좌표로 움직이고 `.fe-fx`(앞 판)에 그린다. 모양 점은 글자(`textPts`: 화면 밖 캔버스에 칠해 넓이로 간격을 정해 고름), 고양이(`catPts`: SVG rect 한 칸에 한 대, 어두운 칸은 불 끔), 격자·흩어짐·점선 윤곽(`outlinePts`)·착륙. 새 모양으로 갈 때 지금 자리와 새 자리를 같은 순서로 늘어놓아 짝지어 엉키지 않게 하고, 같은 점 집합이면 제자리에서 색만 바뀐다. 드론이 떠 있으면(`dHold`) `idle` 불꽃은 쉰다. STUDY1(`dLogo`)은 끝 간판이라 불꽃이 그 아래(화면 26%부터)에서 다시 터진다. 명령마다 `dSeq`를 올려, 늦게 오는 콜백(필기체 글꼴 대기, 흩어진 뒤 다시 모이기)이 다음 대사의 모양을 덮지 않게 한다. 필기체는 `#feScript`(Google Fonts Great Vibes, text=Ilsan)를 엔딩을 열 때 붙이고 0.7초까지 기다린다.
- 산등성이 `hl/hr`에는 둥근 봉우리 항 `cap(t)=.22·√t·(1-t)`이 들어 있다. 깃발은 `bodyTop`(다 쌓인 뒤 산 몸통 윗선: 전체는 봉우리 끝, B1은 쌓인 데) 위에 꽂는다.
