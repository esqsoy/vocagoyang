# 마더텅 Fable UI 이식 — 2026-09-20

마더텅의 화면·글자 칸 입력·발음 표시·캐릭터/효과를 현재 Fable과 맞췄다. 상단에는 기존 제목과 `2026/전체`만 남기고 상단 소리·기록 초기화 버튼은 제거했다. 소리는 Fable처럼 게임 하단에서 조절한다. 별도 발음 버튼 없이 공개된 영어 표제어를 누르면 다시 읽으며, 발음기호는 Fable의 강세 강조 방식을 그대로 사용한다.

원본은 [별도 HTML 백업](../backups/vocagoyangksat2027-20260920-before-fable-ui.html)으로 보존했다. 원본 커밋은 `1722bf409dc49ea6e075deae3adef63f8cf1d982`, 원본 파일 SHA-256은 `72684c6fdb4abb3b1180f8931754b49acfc7c5979a9e6ac7d20d390b7b9200ec`다.

## 유지한 내용

- 17강·521연습·6,498카드의 DATA 전체와 순서, 발음 사전 4,028항목.
- 기존 허용답과 철자 변형 판정, 회독·복습·시간 초과 규칙, 제한 시간, 1,500/650ms 이동.

- Fable와 EBS 파일은 수정하지 않음.

## UI 연결

입력한 글자는 Fable의 밑줄 칸에 표시한다. 공백을 넣거나 붙여 써도 기존 판정과 같다. 마더텅에 실제로 존재하는 악센트·등호 표기를 지원하고 정답을 끝까지 입력하기 전에 자동 오답 처리가 일어나지 않게 한다. 한글 입력과 IME 조합 상태도 화면에 표시하고 조합 중에는 제출하지 않는다.

2026-09-24에는 별도의 ‘키보드로 입력하기’ 버튼과 따라쓰기·입력 방법·반복 정답 횟수·한영 전환 안내를 제거했다. 자동 포커스와 빈칸을 눌러 입력하는 동작, IME 조합 보호는 유지한다. 힌트 버튼을 누르면 단어 단서를 표시하며 정답·오답의 고양이 반응과 발음도 유지한다.

이어 하기는 기존 완료 기록과 별도 `goyang-seoul-last-v1` 선택 위치를 사용한다. 진행 중 회독을 저장하는 기능은 추가하지 않았다. 출제 범위를 바꾸면 현재 연습에서 나와 해당 범위의 홈을 표시하며 완료 기록은 보존한다. 연습을 나가거나 다시 시작할 때 이전 카드의 이동 예약이 새 연습에 끼어들지 않도록 세션을 확인한다.

## 검사

```sh
node pipeline/test-mother-tongue-layout.cjs
```

UI 검사는 전체 카드를 실제 앱 스크립트로 실행하며 원본 데이터·발음·진도 주소와 22개 학습/저장 함수를 기준 fixture에 대조한다. 특수 표기 72개의 퀴즈·따라쓰기 허용/거절 경로, IME·공백·시간·회독·기존 진도·세션 전환을 검증한다. 브라우저에서는 정답/오답 공개·타이핑·모드 선택과 375px 폭의 배치를 별도로 확인했다.

기존 `lab(=laboratory)` 같은 병기 표기는 이번 UI 작업에서 허용답을 임의로 확장하지 않았다. 이 형태의 학습·판정 정리는 별도 어휘 개선 범위로 남는다.
