# 검수 시험지

새 검수 모델이 나오면 같은 시험지로 재 본다. 지난 검수에서 **진짜 결함으로 확인돼 고친 카드**를 '고치기 전' 모양으로 되돌려, 멀쩡한 카드와 섞은 52장이다. 정답(무엇을 왜 고쳤나)을 알고 있어서 몇 개를 잡는지, 멀쩡한 카드에 헛짚는지 셀 수 있다.

- 만든 날: 2026-11-12. 영신: "오늘 최신 ○○가 나왔어. 개발팀(서브에이전트)으로 장단점 파악하고 우리 검수에도 활용해줘." (모델 이름은 저장소에 적지 않는다.)
- 이름: 저장소 문서에서는 이 모델을 **이솝**이라 부른다. 우리 교재 이름 FABLE과 헷갈리지 않게 Claude가 붙였고 26.11.12 영신이 확정했다("이솝은 너의 지혜로운 조력자게 되는거지"). 비교한 쪽은 지금 Claude Code 기본 모델이다(아래 '비교 모델').

## 파일

| 파일 | 무엇 |
|---|---|
| `packet.md` | 시험지 52장. 카드마다 세트·표제어·품사·뜻·예문·해석·해설·고양이 대사. 허용 정답 목록은 없다(해설에 적힌 대체어만 안내된 것으로 본다) |
| `answer-key.json` | 정답. 카드마다 출처(원장 이름), 분류, 고친 칸의 전·후. 그대로인 카드는 `CTRL` |
| `build.py` | 재료 모으기. `python3 pipeline/review-bench/build.py vocagoyangfable.html <폴더>` |
| `score.py` | 결과 한 벌을 정답과 나란히 본다. `python3 pipeline/review-bench/score.py run1-aesop` |
| `PROMPT.md` | 실제 검수에 쓰는 지시문 |
| `results/` | 26.11.12 결과: `run1-aesop`, `run2-compare`, `run3-aesop-tuned`. 실제 검수 `live-26-30`·`live-31-35`~`live-44-45`와 Claude 판정 `live-26-30-verdicts`·`live-31-45-verdicts` |

시험지 구성(90a2b68 기준):

- A 17장: 10-08 리뷰의 검증 통과 결함 중 되돌릴 수 있는 것. 빈칸 중의성 아닌 것 7장은 전부, 빈칸 중의성 29장 중 10장은 무작위로 골랐다.
- B 23장: 뒤 원장(아스트라 10-11·10-13·10-15, 독립 검토 10-13, 이스마엘 10-24)에서 골랐다. 문장부호·한정어·해설 단정·번역투·같은 칸 수 대체어가 섞여 있다.
- 그대로인 카드 12장: 원장에 없는 카드에서 무작위로 골랐다.
- 고르기와 섞기의 seed는 20261112다.

**시험지를 다시 쓸 때:** 검수자가 git 기록·원장·지금 데이터를 보면 답을 알게 된다. 지시문에 '보지 말 것'을 적는다. 이 폴더(정답)도 보지 말라고 적는다.

## 26.11.12 결과

같은 시험지, 같은 지시문(1·2차). 3차는 지시문만 고쳤다(확정·의심 두 단계, 원칙 문서 끝까지 읽기).

| | 이솝 1차 | 비교 모델 | 이솝 2차(지시문 고침) |
|---|---|---|---|
| 지시 | 확신하는 것만 | 확신하는 것만 | 확정 + 의심 따로 |
| 걸린 시간 | 약 2분 | 약 7분 | 약 3분 |
| 지적 수 | 21 | 29 | 확정 22 + 의심 19 |
| 되돌린 결함 40건 중 잡은 것 | 20 (50%) | 26 (65%) + 다른 이유로 짚은 2 | 확정만 21 (53%), 의심까지 35 (88%) |
| 빈칸 중의성 중 학생이 맞는 답을 치고 틀리는 10건(A) | 10 | 10 | 10 |
| 멀쩡한 카드에 헛짚음 | 0 | 0 | 0 (의심 중 근거 약한 것 2건) |
| 그대로인 카드에서 새로 찾은 진짜 결함 | 1 (faithfully) | 1 (같은 카드) | 1 (같은 카드, 의심) |

셈은 Claude가 카드마다 정답과 맞춰 판정했다. 다른 이유로 같은 카드를 짚은 것은 '잡음'에 넣지 않았다.

- **이솝이 잘한 것**
  - 빠르다.
  - 헛짚지 않는다.
  - 원칙 번호를 근거로 단다(예: 2-11 옛 번역투).
  - 의심 목록까지 받으면 가장 많이 잡았다. 사람은 생물학적으로 유인원(ape), without representation 오역(tax), railroad의 미국 쓰임, arguably의 세기처럼 1·2차에서 아무도 못 잡은 결함이 의심 목록에 들어 있었다.
  - 그대로인 카드에서 진짜 결함 하나를 찾았다. 44세트 faithfully에 diligently가 들어간다. 11-12에 반영했다.
- **이솝이 약한 것**
  - 지시문을 그대로 따른다. "확신하는 것만"이라고 하면 지나치게 아껴서, 의심했던 결함(examination·tax·lose·effect)을 버렸다.
  - 1차에서는 원칙 문서를 일부만 읽었다.
  - 의심 목록에는 사람이 가려야 할 것도 섞인다(19건 중 2건은 근거가 약했다).
  - 문장이 자기 자신을 가리키는 오류(clause: 'This sentence has two clauses'인데 절이 하나)는 끝까지 못 잡았다. 비교 모델은 잡았다.
- **비교 모델:** 느리지만 한 번에 고르게 잡았다. 해설의 '만·늘' 단정(night·third·spit)을 1차에서 잡았다. 같은 지시문에서는 이솝 1차보다 많이 잡았다.
- **한계:** 한 번씩만 돌렸다. 시험지가 52장이다. 결함의 반이 빈칸 중의성이다. 숫자는 경향으로만 읽는다.

## 지시문에서 배운 것

- 확정과 의심을 나눠 받는다. 의심은 Claude가 하나씩 판정한다. 버리게 하면 진짜 결함이 함께 버려진다.
- PRINCIPLES 2~4절을 "끝까지" 읽으라고 적는다.
- 실제 검수는 Claude가 판정한 뒤 원장으로 고치고, 영신 직검수 페이지에 함께 올린다. 이솝 결과를 그대로 반영하지 않는다.

## 실제 검수: 26~30세트 Oxford 5000 보강 147장 (26.11.12)

- 이솝: 확정 5, 의심 24, 약 7분.
- Claude 판정: 11곳 반영, 1곳은 맞는 지적이지만 보류, 2곳은 영신 판단, 15곳은 안 고침. 카드마다 판정은 `results/live-26-30-verdicts.json`에 있다.
  - 반영: 해설 대체어 안내 5(expertise·remarkable·publicity·specify·workplace), 해석 3(withdraw·panic·coincidence), 예문 2(spare·screening), 해설 1(myth).
  - 보류: settler에 over를 넣으면 예문이 4줄이 된다. '5만 년'도 틀린 말은 아니다.
  - 영신 판단: firework 고양이 대사가 같은 꼴('~가 아니라 ~라고양')로 되풀이된다. 해석에 '그녀'와 '걔'가 섞인다.
- 시험지에서 찾은 faithfully와 함께 원장 `aesop-review-20261112`(13곳)로 고쳤다. 직검수 페이지: https://claude.ai/artifact/W9krpExrpdSS31wSEovVDa
- 이솝이 경향으로 꼽은 것: 해설이 대체어를 하나만 안내하고, 더 쉬운 같은 칸 수 단어를 놓친다. 앞 세트에서 비슷한 뜻으로 배운 단어끼리 부딪힌다.

## 실제 검수 2차: 31~45세트 Oxford 5000 보강 776장 (26.11.13)

- 영신(11-13 새벽): "나머지도 검수하고 작업완성한 후 푸쉬해줘". 이솝 여섯 묶음(120~146장)을 한꺼번에 돌렸다. 묶음마다 5~6분 걸렸다.
- 이솝: 확정 23, 의심 105.
- Claude 판정:
  - 반영 74건(69장). 확정 22건, 의심 52건이다.
  - 안 고침 49건.
  - 원문 대조로 문제없음 4건.
  - 영신 판단 1건.
- 반영한 것:
  - 빈칸 경쟁어 해설 안내가 가장 많다. persuasive, leftovers, faulty, surreal, apparent, drastic 등이다.
  - 사실을 바로잡은 것: Red Planet은 별명, AlphaGo의 Move 37, 벌은 꽃꿀과 꽃가루, 블랙홀은 한때 이론 속에만, 고흐 편지는 '평생'이 아니라 '오래', 『빨강 머리 앤』은 내기가 아니라 도발.
  - 해설 단정: '명사 앞에만', '셀 수 없이', 'i.e.', 'goodwill ambassador'.
  - 해석의 어색한 말: '절반 넘게가', '날 밀', '젊은 어른'.
- 원장: `aesop-review2-20261113`. 82곳이고, 26세트 settler 3줄 예문도 여기 들어 있다. 처음 고친 안 중 13장은 읽기량 12초를 넘어서 해설을 줄였다.
- 직검수 페이지: https://claude.ai/artifact/Ro4ojTJyfaA3CLxjZVa228
- **명문장 원문 대조:**
  - 이솝은 원문을 볼 수 없어서, 기억에 기대 "원문과 다를 수 있다"고 짚은 카드가 있었다. 바스커빌가 induce는 원문이 the rascals라고 했다.
  - Claude가 구텐베르크 원문 24권을 받아 보강 카드 명문장 46장을 글자 그대로 대조했다. 46장 모두 원문에 있었다.
  - induce의 "Nothing would induce me to help the police in any way."도 원문에 그대로 있다. 이솝이 기억한 rascals는 바로 앞 문단의 다른 문장이었다.
  - 그래서 명문장 확인은 이솝 기억이 아니라 원문 대조로 한다.
- 영신 판단으로 남긴 것: 40세트 injustice는 킹 목사 「버밍엄 감옥에서 보낸 편지」(1963) 인용이다. 저작권이 살아 있어서 '저작권이 끝난 글만' 쓰는 원칙과 맞는지 영신이 정한다.
