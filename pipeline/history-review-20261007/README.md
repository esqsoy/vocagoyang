# FABLE 세계사·과학사 예문 선별 · 2026-10-07

이 폴더는 **검토 자료와 승인된 적용 이력**을 보관한다. `facts.json`의 사실 목록이나 후보 판정은 게임 DATA에 자동으로 들어가지 않는다. 새 영어 예문·해석을 대화에서 모두 보여 준 후 확인받아 적용한다. 첫 30장은 사용자 확인과 시기 보강 지시 후 로컬 반영했으며 공개 배포하지 않았다.

## 목적과 범위

기존 예문의 어휘 학습 가치를 보존하면서, 교체 실익이 있는 문장에 확립된 주요 세계사·과학사 사실을 담는다. 작은 일화나 한국사로 날짜를 억지로 맞추지 않는다. 사건 이해에 도움이 되면 연도 대신 세기 표현도 쓴다.

중요한 사실을 여러 표제어에서 반복하는 것은 허용한다. 같은 문장에 빈칸만 바꾸는 방식보다, 같은 사건의 서로 다른 측면으로 목표 단어의 쓰임을 보여 준다. 반복 횟수나 전체 교체 수에 할당량을 두지 않는다.

## 자료의 의미

- `facts.json`: 세계사 45개·과학사 27개, 총 72개 핵심 주제의 사실·출처·표현 주의점. `core_claim_verified`는 기록된 핵심 주장 확인을 뜻한다. 여기에 연결된 모든 새 문장·인과관계·수치까지 검증됐다는 뜻이 아니다. 전체 세계사·과학사를 빠짐없이 대표하는 완결된 목차도 아니다.
- `early-audit.json`, `middle-audit.json`, `late-audit.json`: 각각 현재 0~13, 14~31, 32~50세트의 모든 카드에 대한 읽기 기록·유지/후보 판정. 표제어·뜻·예문·해설을 읽고 판정했으며, 짧다는 이유만으로 낮은 가치를 매기지 않는다.
- `manifest.json`: 검토 범위와 입력 DATA 해시, 집계·검증 상태.
- `root-review.json`: 최초 후보 630장을 전부 다시 읽은 2차 검토. 기존 문장의 가치·개인화 내용 때문에 18장을 유지로 되돌렸다.
- `candidates.json`: 최종 612카드·568표제어의 교체 후보. 기존 예문·해석·해설, DATA 원본 묶음 위치, 사실 주제와 보존 조건을 함께 남긴다. 일반 연습은 화면에서 다시 나뉠 수 있으므로 이 위치를 최종 분할 exercise 번호로 오인하지 않는다.
- `decisions.json`: 전체 7,067카드의 최종 판정. 유지 6,446장, 신규 교체 후보 612장, 선정 당시 기존 서수 확인 대기 9장이었다. 이후 첫 묶음은 applicationStatus로 구별한다. 후보 수는 변경 확정 수가 아니다.
- `proposal-01.json`: 첫 사용자 검토 묶음 30장. 앞선 날짜·세기 서수 9안을 다시 포함하고 신규 후보에서 21안을 작성했다. 정답을 넣은 전체 문장, 한국어 해석, 함께 정리할 해설 4개, 출처와 주의점을 보관한다. 사용자가 확인한 뒤 15문장의 시기를 보강해 **로컬 적용했다**. fourteenth는 첫 적용 당시 유지했지만 이후 승인된 난도 조정으로 교체했다. 날짜 보강 전 제안은 해당 카드의 reviewedProposal에 남긴다.

전체 카드를 세 구간으로 나눠 표제어·뜻·영어 예문·해설을 읽었고, 후보 630장은 다시 읽었다. 이번 단계에서 기존 한국어 해석까지 전수 검수한 것은 아니다. 판정 누락·중복, 후보의 사실 연결·보존 조건, 검토 시점의 DATA 동일성을 확인했다. 선정 단계에서는 게임 DATA를 변경하지 않았다. 후속 적용은 별도 원장으로 관리한다. 현재 앱의 등록 표제어 기준(`word` 우선, 없으면 `en`)으로 4,916개다.

72개 주제 밖에도 카드와 잘 맞는 중요한 세계사·과학사 사실이 있으면 별도 검증 후 추가할 수 있다. 중국·인도 및 비유럽 지역, 시민권 변화 등 중요한 흐름도 살핀다. 세계대전·산업혁명·우주 개발의 반복 자체는 허용하되 다양한 단어를 모두 같은 소재에 억지로 끼워 맞추지 않는다.

검토용 C0001 등의 번호는 이 시점 DATA의 순번이며 게임의 저장 카드 ID가 아니다. 실제 적용 전에는 manifest의 currentDataHash(최초 적용 전에는 dataHash), 카드 경로·기존 내용이 일치하는지 확인하고 저작 원본으로 역추적한다. dataHash는 최초 전수 선별 시점의 고정 기준이며 currentDataHash와 구별한다. 이 검토 번호를 진도나 저장 기능에 사용하지 않는다.

## 문장 작성·적용 순서

1. 검증된 사실 목록에서 표제어의 해당 뜻에 자연스럽게 맞는 소재를 고른다.
2. 관용적 결합, 품사, 전치사, 비유적 뜻, 유의어 구별을 유지한다. 새 문장이 그 조건을 충족하지 못하면 후보를 철회한다.
3. 초반 세트의 쉬운 생활 영어는 적극 보존한다. 생소한 인명·지명·주변 어휘를 많이 요구하는 역사 문장을 억지로 넣지 않는다.
4. 새 예문과 해석을 작성하고 구체적인 사실과 시기를 출처와 대조한다. 확인 가능한 연도·날짜는 예문에 넣고, 긴 과정은 세기·시대 범위를 쓴다. 핵심 주제와 연결된다는 이유만으로 그 사건의 다른 세부 주장까지 사실로 확정하지 않는다.
5. 기존 해설·고양이 대사가 새 예문을 가리켜도 맞는지 확인한다. 역사 설명을 길게 덧붙이기보다 예문 자체가 간결하고 정확하게 되도록 한다.
6. 한 번에 약 30~40카드씩 전체 영어 예문·한국어 해석을 대화에서 보여 준다. 사용자가 확인한 문장만 저작 원본에 적용한다.
7. 실제 변경된 원장과 조립·관련 보존 검사를 갱신한다. 배포는 별도 요청 범위에서 한다.

예전 1세트 Exercise 11-2의 한국사 포함 로컬 9카드는 첫 묶음 적용으로 대체했다. 별도 [이전 9카드 검토안](../history-examples-major-20261007-proposal.json)은 경위 확인용이며 최신 문장은 proposal-01을 따른다.

첫 30장의 영어 문장·해석·현재 전체 카드 필드를 대조했다. `oxygen`은 주변 어휘 난도를 낮추기 위해 combustion 대신 burning을, `data`는 두 인명을 생략한 짧은 문장을 쓴다. 표제어를 빈칸에 그대로 넣고 보이는 규칙 접미사와 합쳐 올바른 문장이 되는지 확인했다. 기존 설명과 어긋나는 서수 3개 및 knowledge의 설명도 함께 조정했다. 예문·해석·해설 외 카드 정보와 저장 ID·정답 범위·UI는 유지했다.

기준 전문은 [WORK_PLAN](../../WORK_PLAN.md#역사-정보를-담은-예문-선별--2026-10-07-방향-제안대표-검토), 현재 작업 상태는 [HANDOFF](../../HANDOFF.md)를 따른다. 이 검토로 단어를 추가·삭제하거나 게임 방식을 바꾸지 않는다.
