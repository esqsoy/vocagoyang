# 발음 예외 카탈로그 검수

2026-10-15 · 담당 Codex. 구현·생성·배포 상태는 [README](README.md), [HANDOFF](../../HANDOFF.md)를 따른다. 이 문서는 **어떤 발음을 어떤 근거로 등록했는가**를 기록한다.

## 범위와 현재 수치

- [catalog.json](catalog.json): **96개 표제어, 175개 발음형, 187개 원본 IPA 별칭**. `ready` 175개, `hold` 0개다.
- 실제 검토 원본은 FABLE 8,497카드와 마더텅 발음 사전 4,028항목, EBS 발음 사전 545항목이다. 사전의 기본값뿐 아니라 뜻별 `meanings`, 복수 후보 `alternatives`, 문맥을 붙인 `speech`도 조사했다.
- 원본의 복수 IPA 목록 전체를 비교한 다음, **뜻·품사에 따라 실제 발음이 갈리는 말**, 기존에 짧은 문맥으로 TTS를 보정하던 말, 사용자가 제보한 **his**를 선정했다. 괄호·하이픈·소유격·물결표 등을 읽기 좋게 정리한 `speech`는 그것만으로 예외 음원을 만들지 않았다.
- 독립 자료 검수에서 후보 **348카드의 기본 선택 IPA를 카탈로그에서 찾을 수 있었고, 누락은 0**이었다. 이 비교에는 여러 IPA를 함께 제시하는 카드도 들어 있다. 따라서 **348카드 모두가 게임에서 음원을 재생한다는 뜻은 아니다.** 자료의 기본 선택값으로 세면 175개 중 **169개 발음형**이 쓰인다. 나머지 6개는 `alternatives`에만 있는 후보다: `refund-verb`, `estimate-noun`, `import-noun`, `suspect-noun`, `animate-adjective`, `diffuse-verb`.
- **실제 빌드·재생 범위는 305카드**다: FABLE 183, 마더텅 97, EBS 25. 후보 348카드 중 IPA 여러 개를 함께 제시하는 **43카드는 의도적으로 음원 경로에서 제외**하고 기존 문맥 TTS를 유지한다. 애매한 뜻을 추측해 하나만 읽게 하거나, 이 적용 범위를 늘리려고 원본 카드를 바꾸지 않았다.
- 실제 게임 표에 활성화된 것은 **94표제어·155파일·165개의 표제어+IPA 열쇠**다. 준비 카탈로그의 96표제어·175발음형·187별칭, 기본 선택값 대조의 169형, 실제 게임의 155파일은 서로 다른 집계다. 어느 숫자도 전체 카드 수나 영어의 모든 동형이음어 수를 뜻하지 않는다.

## 의미와 발음 선택

1. 현재 카드의 뜻과 예문을 먼저 읽고, 그 뜻에 선택되는 IPA를 확인했다. 마더텅은 원문 발췌도 함께 대조했다.
2. 해당 발음형은 Merriam-Webster의 품사별 발음과 대조했다. 지역·전사 방식 차이 또는 허용 변이인지 불분명한 것은 Cambridge·Collins를 추가 확인했다. 항목별 원자료 링크는 카탈로그 `sources`에 있다.
3. 뜻별 발음 선택은 기존 과정의 선택 규칙을 따른다. 한 카드에 여러 후보가 있다고 모두 읽어 주거나 임의로 새 품사를 추정하는 기능을 추가하지 않는다.
4. 음원 선택 열쇠는 **표제어와 IPA의 조합**이다. 같은 철자라도 강세나 모음이 다르면 다른 음원이다. 카탈로그 `id`의 noun/verb 같은 이름은 해당 발음형을 찾기 위한 설명이며, 그 발음이 오직 그 품사에서만 가능하다는 주장은 아니다.

`address`, `complex`, `discount`, `refund` 등에는 품사별 대표형 외에도 사전이 인정하는 발음이 있다. ‘명사는 무조건 앞 강세, 동사는 무조건 뒤 강세’로 재분류하지 않았다. 현재 한 발음만 가르치고 기존 문맥 보정도 없는 `perfect`, `refuse`, `minute`, `read`, `entrance` 등을 이 작업에서 자동으로 추가하지는 않았다. 이들은 후속 청취 검수 후보이며, 현재 오발음이 확인됐다는 뜻은 아니다.

## 실제 수정·변이 판단

| 항목 | 판단과 처리 |
| --- | --- |
| **contract** | 사용자가 승인한 명사 `kˈɑntɹækt.`·동사 `kəntɹˈækt.` 샘플을 그대로 재사용한다. 현재 IPA에 없는 부강세를 덧붙이지 않았다. |
| **compliment 명사** | 마더텅 ‘칭찬’의 기존 `/ˈkɑmpləmɛnt/`가 명사 발음과 맞지 않았다. 원본 담당자가 `/ˈkɑmpləmənt/`로 수정·재조립한 뒤 그 값만 등록했다. 잘못된 옛 `/mɛnt/` 표기를 `/mənt/` 음원의 별칭으로 묶지 않았다. |
| **implement 동사** | FABLE `/ˈɪmpləˌmɛnt/`와 마더텅 `/ˈɪmpləmənt/`는 Collins가 인정하는 변이다. 원본을 오류로 몰지 않고 각각의 IPA와 맞는 별도 음원으로 보존했다. |
| **subject·object 명사** | 뒤 음절 `/ɪ/`와 `/ɛ/` 변이가 있다. 강세 기호의 표기 차이처럼 합치지 않고 실제 모음이 맞도록 각각 음원을 둔다. |
| **fragment 동사** | 현행 `/fræɡˈmɛnt/`는 Collins American English에 등재된 변이다. Misaki 기본 사전이나 다른 사전의 앞 강세형만 보고 교정하지 않았다. |
| **precipitate 명사** | 현행 첫 모음 `/i/`는 Cambridge 미국식 `/priːˈsɪp.ə.t̬ət/`와 맞는다. 동사의 `/ɪ/`로 통일하지 않았다. |
| **downtown·complex** | 품사만으로 하나의 강세를 강제할 수 없다. 사전의 허용 범위 안에서 현행 앞·뒤 강세형을 각각 보존했다. |
| **refund 동사** | 현행 일부 카드의 앞 강세는 Merriam-Webster가 동사에서도 허용한다. 뒤 강세만 가능하다고 보고 수정하지 않았다. |
| **protest 동사** | 현행 앞 강세형이 사전상 허용되어 오류로 처리하지 않았다. 이번 카탈로그에서는 별도 예외 대상이 아니다. |
| **his** | 사용자 제보를 받아 `/hɪz/`를 직접 지정한다. 실제 제보 기기의 소리가 확보되지 않았으므로 그 브라우저가 `/s/`를 냈다고 확정한 것은 아니다. 어말 `/z/`의 부분 무성화와 잘못된 음소 선택은 구별해야 한다. |

## Kokoro 입력으로 옮기는 기준

Kokoro의 영어 음소 표기는 일반 IPA 문자열과 완전히 같지 않다. [Misaki 미국식 사전](https://github.com/hexgrad/misaki/blob/main/misaki/data/us_gold.json)과 [변환·강세 코드](https://github.com/hexgrad/misaki/blob/main/misaki/en.py)를 확인하고, **검수한 현행 IPA**를 아래 규칙으로 옮겼다. Misaki 사전의 기본 발음을 그대로 복사해 현행 모음·강세를 바꾸지 않았다.

| 현행 IPA | Kokoro 입력 |
| --- | --- |
| eɪ, aɪ, oʊ, aʊ, ɔɪ | A, I, O, W, Y |
| tʃ, dʒ | ʧ, ʤ |
| r | ɹ |
| ɚ, ɝ | əɹ, ɜɹ |
| 해당 사전에서 DRESS 모음을 나타낸 단독 e | ɛ |
| 음절 구분점, 장음 기호 ː | 음소 입력에서는 생략; 원본 IPA 별칭은 그대로 보존 |

- 강세 기호는 Misaki 방식에 맞춰 **강세 음절의 모음 직전**에 둔다. 예를 들어 `/prəˈdʒɛkt/`는 `pɹəʤˈɛkt.`다. 위치를 옮긴 것이지 강세 음절을 바꾼 것은 아니다.
- 원래 강세가 표시되지 않은 단음절 21개에는 고립 단어를 발음하도록 주강세를 지정했다. 다음절에 임의의 주강세를 새로 부여하지 않았다.
- 음원이 단독 단어로 끝나도록 끝에 마침표를 붙인다.
- `separate`, `impact`, `estimate`, `associate`의 부강세 표시 유무만 다른 별칭 4쌍은 하나의 발음형으로 묶었다. 주강세 차이나 실제 모음 차이를 이 규칙으로 합치지 않는다.
- `ipaAliases`는 원본 문자열 그대로다. 전사 차이인 `e/ɛ`, 장음 표시, 음절 경계만 다른 형태가 같은 음원으로 모일 수 있지만, `/ɪ/`와 `/ɛ/` 같은 실제 모음 차이는 별도 형으로 둔다.

## 독립 검수와 한계

카탈로그 작성자와 별도 검수자가 다음을 확인했다.

- 175개 항목 전체를 직접 읽고, 별도 변환기로 음소 순서·이중모음·강세를 대조했다. **불일치 0**.
- 실제 생성 모델의 tokenizer 어휘와 대조했다. **지원하지 않는 기호 0**. 모르는 기호를 조용히 버리고 생성하는 방식은 쓰지 않는다.
- 뜻별 IPA를 실제 카드와 다시 연결했다. 후보 348카드의 **기본 선택 IPA 카탈로그 대조 누락 0**. 그중 복수 IPA 43카드를 제외한 **305카드만 실제 음원 경로를 사용**한다. 자료 대조의 누락 0을 전체 348카드의 음원 재생 확인으로 해석하지 않는다.
- 독립 대조에서 발견한 25개 표기 차이는 위에서 밝힌 단음절 강세 추가 21개, 부강세 표시 차이 4개와 일치한다.

이는 **자료와 합성 입력의 검증**이다. 175개 파일을 사람이 모두 청취했다는 뜻은 아니다. 생성·디코딩·재생 및 실제 청취 결과는 생성 담당자의 기록을 따른다. 지원 기호만 사용했다는 사실만으로 합성음의 모든 자음·모음·강세가 정확하다고 보장하지 않는다. 특히 짧은 단어의 어말 유성음, 음원 가장자리, 드물게 쓰이는 발음형은 실제 소리도 확인해야 한다.

사전의 음원 파일을 복제하지 않았다. 사전에서는 발음 사실과 허용 변이를 확인했고, 오디오는 승인된 Heart 음성과 직접 지정한 음소로 제작한다. 기본 브라우저 TTS 전체의 발음을 교정하거나 정밀한 음절 동기화를 완성한 작업으로 표현하지 않는다.
