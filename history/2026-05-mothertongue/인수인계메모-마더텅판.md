- **단일 HTML 파일**(`vocagoyangksat2027.html`) 하나로 완결. 외부 의존성 0. 핸드폰으로 열어 학생에게 배포.
- 모바일(폭 ~560px) 세로 기준 레이아웃.
- **숨은 설정**: 고양고양이 = 사실 강사 "영신초이"(ㅇㅅㅊ, 03학번)의 분신. 엔딩·대사에 슬쩍 복선.

## 3. 데이터 구조 & 교체 방법
- 단어는 HTML 안 한 곳에 모여 있음:
  ```
  /*==== WORDSET DATA START (이 줄과 END 줄 사이만 통째로 교체) ====*/
  const DATA = [ ... ];
  /*==== WORDSET DATA END ====*/
  ```
- 스키마: `[{ "lesson":1, "name":"글의 목적 파악", "exercises":[ {"ex":1,"scope":"2026","words":[{"en":"...","ko":"..."}]} ] }]`
  - `scope`: `"2026"`(올해) 또는 `"prev"`(이전 기출).
- **새 교재 교체 파이프라인** (.hwp → DATA):
  - 원본은 한글 .hwp 5.x, 표 구조(번호|영어|뜻).
  - `pip install pyhwp --break-system-packages` 후 **`hwp5proc xml`** 사용(빠르고 안정적). ⚠️ `hwp5html`은 큰 파일에서 멈추니 쓰지 말 것.
  - XML에서 `<TableControl>`(=연습)→`<TableRow>`→`<TableCell>`→`<Text lang="en/ko">` 추출.
  - 셀 내 여러 `<Text>` 런은 **공백 없이** 이어붙일 것(안 그러면 "t ime" 깨짐). 복합어 내부 공백은 한 런 안에 있어 보존됨.
  - 행마다 영어 셀→다음 한글 셀 = (en,ko). 헤더행("영어 단어/한글 뜻") 스킵. 파일1개=1강, 파일명 순서=유형 순서.

## 4. 핵심 기능 (모두 구현됨)
- **2026 / 전체 토글**(상단 버튼): 기본 2026만. 전체=이전 기출 포함. 진행률·단어수 분모가 모드 따라 바뀜. 기록은 한 곳에 통합.
- **고양이 = 확인 버튼**: 입력창 옆 흔들리는 고양고양이를 탭하면 제출(`<button type=submit>`). 숨겨진 `#submitBtn`은 JS용이라 **삭제 금지**.
- **따라쓰기(오답) 오버레이 순서**(위→아래): 단어뜻 라인 → 따라쓸 단어 → 조롱 대사 → 고양이.
- **다음 강 이동**: 강 마지막 연습 클리어 시 버튼이 "다음 강 ▶"으로 바뀌고 다음 강 첫 연습으로 직행(`nextLessonIndex`).
- **강 클리어 멘트**: 한 강 완료 시 "○○개 단어를 다 확인했다고양!" + 강별 멘트(`LESSONCLEAR` 맵, 1~17 각각 다름).
- **100% 엔딩**: 탈출률 100% → 대학명 입력 → "○○ 쌉가능이고양!" 팝업(3종 랜덤, 정체 누설 변주 포함). 상단 지도 탭하면 재오픈.
- **레이아웃**: 게임 화면 순서 = 입력창→단어카드(위 정렬)→정보패널. 진행바(maproute) 맨 아래.
- 홈 카드: 2줄(강번호+유형명 / N연습·N단어), 진행률은 텍스트(%/완료 ✓).

## 5. 정답 판정 철학 (중요 — 사용자가 확고함)
- **판정은 절대 안 느슨하게**. 정답 영단어 **정확히 그 단어만** 정답.
- **철자 변형**(maximise↔maximize, US/UK 등 `isSpellingVariant`): **정답 처리하되** "이 책은 ○○로 쓴다고양" 안내. (같은 단어라 인정)
- **완전 동의어**(various↔diverse 등): **오답 유지** + 교육 멘트 "한글론 같은 뜻인데 영어 쓰임이 다르다고양. 지문에서 어떻게 쓰였는지 기억하라고양!"(`SYNLINES`, `isSynonymMiss`가 책 안 동의어 자동 감지).
- 모호함은 동의어의 본질이라 데이터로 안 건드림(지문 맥락으로 학습).

## 6. 보조 힌트 (B, 수동)
- `HINTS` 맵: 책에 **없는** 흔한 단어로 착각하는 케이스용(예: `time-honored`에 "traditional 아님" 시안색 표시). 키=영어 정답(소문자). 필요한 단어만 등록.

## 7. 대사(LINES) 시스템
- `const LINES = { welcome, start, correct, correctStreak, wrong, timeout, exerciseDone, lessonDone, allDone }`, 랜덤 픽.
- **조롱 = wrong/timeout**(오답·시간초과 시 따라쓰기 화면).
- 인사이드 조크 (학생들 저격): **영신초이/STUDY1/〔옆 건물 상호 — 공개 저장소라 생략〕**, **클래식 드립 시리즈**("이런 호로비츠!/피아졸라!/슈베르트!/시벨리우스!" — 〔학교명 생략〕 학생용).
- 특정 실명 대학 언급 금지(서울대 등 제거 완료). "인서울대학교"는 컨셉이라 허용.
