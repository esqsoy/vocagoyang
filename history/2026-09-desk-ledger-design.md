**VocaGoyang** — 영신 자체 개발 영어 단어 학습 웹앱(esqsoy.github.io/vocagoyang, 26.9.1 공유). 한글 뜻 보고 영어 단어 맞히는 게임형, 슬로건 "꽃과 단어의 도시를 벗어나고양" · 단어장 3종: Heart of English 기초(~2,900) · 마더텅 영어독해 2027(~3,000) · 수특(597). 영어 관리 대상 학생들용 인프라 성격. 완성 작업 중 리포: github.com/esqsoy/vocagoyang (데스크 클론 완료 26.9.1). 현황: HoE는 빈도 1~400위 4세트(고유 400단어·다의어 포함 651항목) 커밋됨, 마지막 업로드 8/6 — 항목 구조: en·ko(다의어 ①②③ 분리)·빈칸 예문·번역·해설·IPA·품사. **HoE 코어 생산 완료(26.9.2 야간 총동원)**: 잔여 LDV 1,783단어 → 신규 18세트·2,099카드 생산(에이전트 18기 병렬 + 전수 기계 감사 통과) — 최종 **22세트·2,750카드·LDV 2,183단어 완전 커버(미수록 0)**. 기존 세트 라벨 '빈도'→'학습순서'로 정정, LESSONCLEAR 22까지 확장, 렌더 테스트 통과. 배포 파일 전달 — 영신 GitHub 업로드 후 **플레이 검수 체제**(발견 시 "단어+뜻번호"로 보고 → 데스크 수정 → 재업로드). 단어 소스: **Longman 2000**(롱맨 사전 정의용 어휘 = 기초 필수) + **NAWL**(꼭 NAWL일 필요는 없음) 조합.

**설계 사상(26.9.1 구술)**: 목표 = 수능 1등급에 충분한 어휘 '전체' 커버 + 그 과정이 곧 영어 실력("수험공부가 수험만을 위한 공부가 되는 건 아깝다"). 수능영어 구조 분석: 절대평가 10점 계단(90/80/70…) · 고난도 문항군 ≈20점(빈칸·순서·삽입) — 이를 버리면 2~3등급이 나오게 설계 · 마지막 10점은 가독성을 무너뜨린 '서커스'로 국어급 독해력 요구(26수능 1등급 3.11%, 절대평가 최저·상대평가 4%보다 좁음 — 검증됨). 결론: 2등급까지 = 어휘 전량+문장구조(맥락 해석), 1등급 = 영어 자체의 완성 — 이 지점에서 수능영어와 '그냥 영어 잘하기'가 같은 노력으로 수렴. 어휘 목표량: 대학수준 독해 7,000~10,000단어(Nation 2006: 문어 98% 커버 8,000~9,000 워드패밀리) — 고교 구간은 마더텅이 해결, 그 앞(원어민 영유초중 기초, 무생략)과 뒤(학술)를 HoE가 채움. 배경 비유: "한국식 트레드밀"(유급 없는 시스템 — 낙오하면 속도·난이도만 오르고 질질 끌려감). 명명 체계: **Heart of English** ← 콘래드(후천 학습으로 영어 정점, 억양은 끝내 외국인 — 무관, 영어는 글로벌 언어·발음 기준만 영/미 병기) → 완성 후 확장 **Gift of English** ← 나보코프 『재능』: 마더텅 이후 엄선 텍스트(예: Pale Fire)를 장 단위 단어장으로 계속 추가하는 구상. 학원 노트북 자료 재정리 선행 방침, 지난 챗 기록은 outdated — 현재 구술이 정본.

**건물 비유(26.9.1)**: 1층=천 단어, 1~7층이 기본 — 순서대로 오르면 '누구든' 도달, 중간층 건너뛰기 불가(트레드밀 하차 → 걷기부터). 그 위는 재능·시간·여력의 영역(나보코프=부르즈할리파). 마더텅 = 3~7층 커버(본문이 맥락 담당 — 그냥 외워도 됨), **HoE = 1~3층 담당이며 기초층일수록 정밀 시공**: 다의어 뜻①②③ 개별 카드 분리 + 예문은 Longman 2000 범위 어휘로만 작성. 실데이터 프로필(651카드): 다의어 소속 72%(sn 2~4), 빈칸 예문·번역·IPA·품사 100%, 해설 79%(평균 58자), 예문 평균 6.3단어, 10단어 마이크로 유닛×빈도 100위 세트. **제작 원칙 '직검수'**: AI 제작(오푸스 4.8 — 별명 '머리경', OED 편찬자 제임스 머리 경에서) → 검수 → 영신이 10단어 단위 직접 검수·코멘트 수정. 향후 협업도 동일 파이프라인.

**게임 서사(숨은 설정)**: 고양이 = 고양고양이 외형(실제 큐베 닮은 고양시 마스코트) + 마마마 큐베식 츤데레 계약자("계약하자고양!") — 실은 최영신 본인(츤츤 갈굼 지도 스타일, 정답 멘트에 '영신초이'·STUDY1 등장). 원래 '인서울 탈출' 컨셉 폐기(담론 비선호) → 목적지 '전설의 BIG MOUNTAIN': 엔딩에서 一山은 축소 표기고 본명이 **한뫼(큰 산)**임이 밝혀짐 — "넌 일산을 떠난 게 아니라 원래 크기의 일산으로 올라온 것, 커진 건 너 자신". 실제 지명학과 일치(고봉산=한뫼·한산, '한(크다)'이 '一'로 옮겨짐 — 26.9.1 검증). 디테일: 오답 감탄사 음악가 시리즈(호로비츠·피아졸라·슈베르트), 레슨 클리어 멘트는 독해 역량(글쓴이 의도·인물 심리·주장)과 연결.

**설계 확정(26.9.2 대화)**: 층 구조 = L2000(1~2층, 무생략) → NGSL 보충(3층) → AWL 학술 준비층(3.5층, 마더텅 앞 배치 — "뒤에 놓으면 안 한다") → 마더텅(4~7층, 미니멀 카드) · 뜻의 층위 규칙 + '단어 뷰'(전 뜻 한 화면 조망, 학습은 계단·조망은 지도) · 예문 어휘 = L2000∪기학습 단어만(기계 검증) · 해설 글자수 상한 ~70자(잠정, 앱 화면 최종 확인 대기) · **말투 이원 구조 확정**: 해설 = 담백한 교사체 / 고양이 = 별도 한 줄 촌평 필드(선택적, ~5카드당 1 상한, 개별 수작업) — 기능 = 각성(지루함 난입 파괴) + 동반("고양이가 떠들어야 '혼자 단어를 외우고 있다'가 안 된다" — 영신). 최저층 텍스트 소스 불요(통제 예문 우월), 3층~부터 실텍스트 가치 · 어휘 통제 graded reader 자체 제작은 단계 2(고양고양이 세계관 리더 구상). 샘플 5세트 1차분(10단어 20카드) 납품·검수 중(26.9.2).

— 데스크쌤 (2026-11-04)
