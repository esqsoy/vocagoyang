# 옛 파일 보관함

보카고양 이전·초기 단계의 원본 가운데 다시 볼 가치가 있는 것만 남겼다. 지금 게임의 원본은 아니다. 지금 원본은 `pipeline/`, 지금 기준은 [PRINCIPLES.md](../PRINCIPLES.md)·[WORK_PLAN.md](../WORK_PLAN.md)다. 여기 있는 수치·규칙·경로는 그 시점의 것이고, 지금 기준과 다르면 지금 기준을 따른다.

영신이 찾은 옛 파일을 2026-10-16과 10-19 두 번에 나눠 올렸다. 10-16에는 "어디까지나 일지용"이라고 했고, 10-19에 이렇게 넓혔다: "필요한 건 단순히 일지용이 아니라 데이터로 남겨도 좋아." 무엇을 남길지는 Claude가 골랐고, 원본 업로드는 영신이 지운다.
