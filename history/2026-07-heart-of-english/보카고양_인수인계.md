**마더텅과 중복돼도 그대로 둔다.** 기초에도 나오고 수능에도 나오면 중요한 단어다.

제호는 **Heart of English** (콘래드 『Heart of Darkness』 — 빈도순 정렬 = 강을 거슬러 언어의 심장부로).

## 3-b. ⚠️ 구조 변경 — 변별(v) 필드 폐지

**옛 `v`(변별) 필드를 `c`(해설)로 통합했다. `v`는 더 이상 없다.**

이유: 필드를 나누니 오분류가 생겼다. `pay for the meal / pay the waiter`처럼
**같은 단어의 용법 차이**를 '변별'에 잘못 넣는 사고가 실제로 났다.
해설은 원래 **강사가 필요한 것을 그때그때 설명하는 자리**다 — 예문 들고, 문법 짚고,
헷갈리는 것 갈라주고. 하나가 맞다.

**함정·혼동은 `[주의!]` 표지로 문장 안에 표시한다:**
```
"목적어를 눕혀 놓는 타동사. [주의!] lie(눕다)와 최악의 혼동 짝이다 —
 lay(~을 놓다) lay-laid-laid는 목적어가 꼭 필요하고, lie(눕다) lie-lay-lain은 과거형이 하필 lay다."
```

> ### 🎯 핵심 원칙
> **데이터는 한 덩어리로 준다. 배치는 게임이 결정한다.**
>
> 예문식 알림 / 문법 설명 / 주의 표지 / 유사어 구별 — 이걸 화면에 **어떻게 쪼개 보여줄지**는
> 게임 쪽이 궁리할 몫이다. 우리는 내용만 정확하게 만든다.
> `[주의!]` 표지를 잡아 강조 스타일을 주거나, 문장 단위로 쪼개 단계 노출하는 등
> 자유롭게 설계하면 된다.

## 4. ⚠️ 가장 중요한 변경 — 말투는 그쪽이 입힌다

**마스터는 평서체(중립)다.** 고양이 말투를 전부 걷어냈다.

- 이유: 마스터를 **중립 자산**으로 만들어 게임·docx·시험지에 재활용
- **"~고양" 말투는 게임 렌더 단계에서 입힌다.**

```
마스터:  "few friends(친구가 거의 없다) / a few friends(친구가 몇 있다)처럼, a가 붙으면 뜻이 뒤집힌다."
게임:    "a가 붙으면 뜻이 뒤집힌다고양! few는 없고, a few는 있는 거라고양~"
```

**정보량 없는 해설은 아예 삭제했다(배포분 71건 + 미검수 148건).**
white("흰색의"), star("하늘의 별") 같은 동어반복은 뺐다.
→ **해설이 비어 있는 카드에서는 고양이가 자유롭게 개드립 쳐도 된다.**

*기계 치환은 금물(조사·어간이 깨진다). 문장 단위 재작성이 원칙.*

## 5. 🔴 반드시 고쳐야 할 것 — 복습 카테고리

현행 보카고양 메커니즘 분석 결과:

- **진도 저장:** localStorage에 연습 단위 클리어 기록(completed/bestMs/errors) → 탈출률 %
- **오답 재출제(회독):** 1회독 전체 → **2회독부터 틀린 것만** 2연속 정답 요구 → 3회독 무작위
  → 세션 안에서는 견고하다.

**❗ 문제: 세션이 끝나면 오답 기록이 증발한다.** localStorage엔 "깼다/못 깼다"만 남는다.
즉 **날짜를 건너뛴 복습(망각곡선 대응)이 없다.**

> ### 요청
> 1. 세션 종료 시 **오답 단어를 별도 localStorage 키에 append**
> 2. 다음날 **'복습' 레슨**으로 환류 (누적 오답만 출제)
> 3. 장기: 오답 CSV 내보내기 → 수기 시험지와 연동

**이것이 배포의 전제 조건이다.** 기초 어휘는 반복이 생명이라 세션 내 재출제만으론 부족하다.

## 7. CSV로 갈 경우 — 한글뜻 충돌 0 필수

기존 3열 규격(`카테고리/한글뜻/영어`, UTF-8 BOM)을 쓴다면, **같은 카테고리 내 한글뜻 충돌 0**이 필수다.
뜻 차이는 이미 마스터의 `v`(변별) 필드에 심어뒀으니 괄호 힌트로 갈라주면 된다.

| 쌍 | 차이 | 한글뜻 제안 |
|---|---|---|
| little / small | 귀여운 느낌 / 중립적 크기 | 작은(정겨운) / 작은(크기) |
| big / large / great | 일상 / 크기·수량 / 추상적 정도 | 큰(일상) / 큰(수량) / 큰(정도) |
| part / area | 쪼갠 조각 / 넓이 있는 구역 | 부분(조각) / 지역·분야 |
| kind / type | 거의 같음, type이 분석적 | 종류 / 유형 |
| idea / plan | 떠오른 발상 / 짜인 계획 | 생각·발상 / 계획 |
| group / class | 아무 무리 / 배우는 반 | 무리·집단 / 수업·반 |
| live / stay | 오래 삶 / 잠시 머묾 | 살다(거주) / 머무르다 |
| place / point | 넓이 있는 장소 / 하나의 점 | 장소 / 요점·지점 |
| main / chief | (기존) | (기존 유지) |

**단, 클로즈 예문 구조를 살린다면 CSV보다 JSON 직접 사용을 권한다.**
우리 데이터의 값어치가 예문·해설·변별에 있는데 CSV 3열로는 다 버려진다.

## 8. 데이터 특징 (게임화 참고)

### 클로즈 예문
밑줄 수 = 정답 글자 수. 규칙 어미(s/ed/ing)는 밑줄 밖 노출.
```
"The class _ _ _s at three o'clock."   → 답: end (s는 밖)
```
**정답 유일성**을 검수 중이나, 유의어가 들어갈 여지가 남을 수 있다.
→ **오답 처리보다 "그것도 맞지만 우리가 찾는 건 ~"** 이 교육적으로 낫다.

### 품사 페이딩
`pos_full: true`인 뜻에서만 풀네임 설명을 띄운다(**블록별 첫 2회**).
근거: 전문성 역전 효과 — 초보에게 도움되는 설명이 숙련자에겐 인지부하가 된다.

> **게임은 적응형으로 확장 가능:** 품사를 틀린 학생에게만 설명을 다시 띄우기.
> 연구상 고정 페이딩보다 적응형이 낫다. docx는 못 하지만 게임은 이력이 있으니 가능.

### det.(한정사) 상세 설명
한국어에 없는 범주라 유일하게 길게 붙어 있다:
> 명사는 **반드시 하나의** 한정사(무관사 ∅ 포함)를 가진다.
> 관사 a/an/the/∅ · 양 many,few,no · 지시 this,that · 소유 my,your
> ∅는 '없음'이 아니라 '전체·일반'의 선택. 단수 가산명사는 ∅ 불가.

관사 오류의 뿌리를 뽑는 자리다. **한 번은 제대로 보여주는 게 좋다.**

## 9. 절대 하지 말 것

1. **`tag` 필드 노출 금지** — "뭉치: see/look/watch" 같은 내부 메모다.
2. **`reviewed: false` 배포 금지** — 미검수분이다.
3. **한 카드의 뜻 순서를 섞지 말 것** — "다음 ②③④에서 익힌다" 식 상호참조가 있다.
