# 영어 어휘 프로젝트 좌표

> 살아있는 문서. 세션·도구가 바뀌어도 이 문서가 진실의 기준.
> 최종 갱신: 2026-07-12 · 담당 페르소나: **머리경** (Sir James Murray, OED 편집자)

---

# I. 제호와 철학

> # Heart of English
> *어떤 번역도 거치지 않고, 언어의 심장부에 직접 닿기* — **1~4단계 (콘래드 라인)**
>
> # The Gift of English
> *심장부에 닿은 자가 언어를 누리다* — **5단계~ (나보코프 라인)**

**콘래드 = Heart.** 『Heart of Darkness』가 강을 거슬러 핵심부로 들어가는 이야기이듯, 우리도 영어의 변두리(번역·자막·시중 단어장)에서 시작해 **언어의 심장부 — 원어민도 의식 못 하는 기초어의 작동 원리 —** 로 거슬러 올라간다. 콘래드의 강 = 우리의 **빈도순 정렬**. 하류(고빈도 생활어)에서 상류(학술어)로, 한 단어씩.

강 끝에서 마주하는 것은 공포가 아니라 **"아, 이게 다였어?"** 하는 투명함이다. 기초어를 끝까지 장악하면 영어가 더는 안개가 아니게 되는 순간. *별거 없다. 하지만 거기 모든 게 있다.*

**나보코프 = Gift.** 『The Gift』는 한 청년이 자기 재능을 자각해가는 성장소설. 심장부에 닿은 자가 이제 언어를 **가지고 노는** 단계. 장악을 넘어 **유희**로. 기초를 다진 자에게 영어가 비로소 *선물*이 된다.

두 제목이 여정의 두 국면을 나눈다 — **닿기(Heart) → 누리기(Gift).** 콘래드의 노동에서 나보코프의 재능으로.

*(부기: 나보코프 『The Gift』의 원제는 러시아어 **Дар**. 번역을 거쳐 영어가 된 제목을 우리가 되가져오는 셈이라, "외국어를 장악한다"는 주제가 제호의 내력에마저 박혀 있다. 스페인어 dar와 같은 인도유럽조어 뿌리 \*deh₃-.)*

**교육 철학 (전 과목 공통):** 구조적 틀은 주되, 세부는 스스로 발견하게 한다. 과잉 비계 금지.

# II. 전체 커리큘럼 지도

### 콘래드 라인 — 후천적 습득

| 단계 | 어휘 풀 | 규모 | 도구 | 상태 |
|---|---|---|---|---|
| **1단계 · 기초** | **롱맨 2,051 + NAWL 963** | **3,014** | **개조 보카고양** (별도 엔진) | **진행 중** — 본 문서 |
| **2단계 · 수능** | 마더텅 기출 | ~6,000 | 보카고양 (기존) | ✅ **완성** |

### 나보코프 라인 — 유희 (현재 무시)
문학 텍스트 기반 고급어. 예: *Lolita*를 챕터 단위로 뜯어 고급어 추출 → 단어장화.

### 확정 사항
- **차집합 처리 안 함.** 롱맨∩NAWL = 약 88개(9%)뿐이고, 그마저 롱맨 뒷순위에 몰려 있어
  학생이 만날 땐 이미 배운 뒤다. 겹치면 **자연스러운 복습**이 된다. 그냥 이어붙인다.
- **구조독해(구 3단계)는 프로젝트 밖.** 영신이 수업에서 직접 한다.
  → 프로젝트 = **어휘 전문 도구**. 다만 1단계 카드에 통사 지식이 자연히 박혀 있다
  (한정사 자리 판별, forget to/-ing, 형용사·부사 분화 등).
- **두 게임은 인덱스(선택화면)로만 묶고 엔진은 분리.**
  기초 = 정밀 학습(예문·해설·변별·IPA·품사 전부 활용) / 수능 = 속도 암기(한글뜻→영어 타이핑)
- **마더텅과 중복돼도 그대로 둔다.** 기초에도 나오고 수능에도 나오면 중요한 단어다.

### 산출물 3종 (모두 **블록=100단어** 단위)

| 산출물 | 용도 | 비고 |
|---|---|---|
| **게임** (개조 보카고양) | 익히기 | 매일 플레이 |
| **수기 시험지** | 확인하기 | 다음날 테스트, 영신이 직접 채점 |
| **학생판 docx** | **맞춰보기** | **시험지 답안 겸 참고서** |

**학생 동선:** 게임 플레이 → 다음날 수기 테스트 → docx로 답 맞추기.
docx를 답안으로 주면 반드시 펴게 되고, 오답 확인하며 해설·변별·IPA를 자연히 보게 된다.
*(문제형 docx(답 가림)는 나중에 렌더 옵션으로 일괄 추가. 지금은 답안형 하나에 집중.)*

**일일 분량:** 실측으로 결정 (100~200 예상, 고3은 더).

### 풀별 독립 관리 (`pool` 필드)

| 풀 | 규모 | 성격 | 세트(20) | 블록(100) | 상태 |
|---|---|---|---|---|---|
| **longman** | 2,051 | 기초 생활어 | 103세트 (끝 11개) | 21블록 (끝 51개) | 1,050장 제작 / 180장 검수 |
| **nawl** | 963 | 기초 학술어 | 49세트 (끝 3개) | 10블록 (끝 63개) | 미착수 |

**세트·블록 번호는 풀 안에서 리셋된다.** (롱맨 1세트, NAWL 1세트가 각각 존재)

### ⚠️ NAWL 착수 시 필수 작업

**NAWL은 SFI(빈도지수) 순으로 재정렬해서 쓴다.**
원본은 알파벳순이라 abdominal(SFI 50.9, 의학 전문어)이 1번이고 obtain(SFI 66.5, 최빈출)이
한참 뒤에 나온다 — 그대로 쓰면 학습 순서가 무의미하다.

재정렬하면 앞머리가 이렇게 온다:
`obtain(66.5) · distribution(65.7) · aspect(64.2) · dynamic(63.5) · impact(63.5) · domain(63.5) · denote(62.6) · authority(62.5)`
꼬리는 `descendent(38.9) · mall(41.2) · calculator(41.8) · chess(43.6) · hawk(42.9)` — 저빈도 잡어.

*목록 확보: newgeneralservicelist.org에서 다운로드(무료). 웹 페치로는 a~o 613개만 받히므로
NAWL 착수 시점에 영신이 파일 업로드 → SFI 정렬 → `nawl_words.json` 생성.*

**독립시키는 이유:** 롱맨(생활어)과 NAWL(학술어)은 성격이 달라, 한 세트에 뒤섞이면
난이도 점프가 세트 중간에서 일어난다. 풀을 나누면 학생이 "롱맨 끝, 이제 학술어" 를
명확히 인지하고, 게임 인덱스도 세 갈래로 깔끔하게 갈린다. 자투리 세트는 그냥 둔다.

*세트를 20으로 잡은 근거: 마더텅(수능)이 10~20개 단위인데 기초어는 난이도가 훨씬 낮으므로
20이 적당. 50은 한 판이 너무 길어 "엘리베이터 한 층씩 쳐내는" 감각이 안 난다.*

# IV. 데이터 구조 (`hoe_master.json`)

```jsonc
{
  "cards": [{
    "n": 1,                      // 빈도 순위 = 카드 번호
    "word": "one",
    "pool": "longman",           // longman | nawl — 풀별 독립
    "set": 1,                    // 20개 단위 (플레이) — 풀 내 번호
    "block": 1,                  // 100개 단위 (진도·페이딩) — 풀 내 번호
    "z": "6.5",                  // 원본 빈도값
    "ipa": "wʌn",                // 음절경계 '.', 주강세 'ˈ', 부강세 'ˌ'
    "tag": "다의어",              // ★내부용 — 학생판 비표시
    "reviewed": true,            // ★영신 직접 컨펌만 true
    "form": "know-knew-known",   // (선택) 불규칙 변화
    "senses": [{
      "g": "① 하나(의), 한 개",    // 뜻풀이 (품사 괄호 없음)
      "pos": "num.",             // 품사 약어
      "pos_full": true,          // 세트별 첫 2회만 true → 풀네임 병기
      "ex": "I have only _ _ _ brother.",
      "ans": "one",
      "tr": "나는 형제가 하나뿐이야.",
      "c": "해설 — 강사가 필요한 것을 설명하는 자리 (없을 수 있음)"
      // ★ v(변별) 필드는 2026-07-12에 c로 통합·폐지됨
    }]
  }],
  "pos_gloss": { "n.": "noun 명사 — ...", "det.": "(상세 설명)" }
}
```

## 품사 체계
`n. v. adj. adv. prep. conj. pron. det. num. int.`

**페이딩:** **블록(100단어)별 첫 2회**만 풀네임+한국어 병기 → 이후 약어만.
- 근거: 전문성 역전 효과(초보에겐 도움, 숙련자에겐 인지부하) + 블록 경계가 자연 간격 제공
- 실측: 300단어 495뜻 중 병기 **51개(10%)**. 블록마다 **품사별 정확히 2회씩** 균등.
- 세트(20)가 아니라 블록(100) 기준인 이유: 20마다 리셋하면 품사 설명이 도배된다.
- 희귀 품사(conj./prep./int.)는 등장이 적어 나올 때마다 풀설명 → 자동 균형

**det.만 상세 설명** (한국어에 없는 범주라):
> 명사는 **반드시 하나의** 한정사(무관사 ∅ 포함)를 가진다.
> 관사 a/an/the/∅ · 양 many,few,no… · 지시 this,that… · 소유 my,your…
> ∅는 '없음'이 아니라 '전체·일반'의 선택. 단수 가산명사는 ∅ 불가.

**num.**은 독립 품사로 두되 "한정사 자리에 올 수 있다"고 연결.
**자·타동사 라벨 없음** — 대신 전치사 동반을 예문으로 못 박음 (wait for me).

# V. 품질 규범

1. **뜻 분리** — 품사가 다르거나 뜻·용례가 갈리면 반드시 ①② 분리, 각자 예문·답·해석.
   슬래시는 동의어 나열에만. 예외: football, minute.
   *형용사·부사 동형(early, late, hard, pretty)은 반드시 분리.*

2. **빈칸** — 밑줄 수 = 답(기본형) 글자 수. 규칙 어미(s/ed/ing)는 밑줄 밖 노출.
   **예문에 답을 넣었을 때 비문이 되면 안 됨.** y→ies 복수는 단수 예문으로 우회.
   **정답 유일성:** 같은 글자 수의 유의어가 들어가도 말이 되면 예문을 조인다 (area/part 등).

3. **문체 = 평서체** ★2026-07 변경
   - 데이터는 **중립 자산**. 고양이 말투는 **보카고양에 넣을 때 렌더 단계에서 입힌다.**
   - 이유: 마스터를 교사판·학생판·게임·다른 페르소나에 재활용 가능하게.
   - 종결 `~이다/~한다`. 금지 `~라고양`, `~이야`, `~해봐`, `~하자`.
   - 재작성은 **문장 단위**로. 기계 치환 금지(조사·어간 파탄 발생).

4. **예문 선행 원칙**
   - 구문·규칙 설명은 **예문이 먼저**: `my own room(내 방)처럼, 소유격 뒤에 붙어 ~`
   - 다의어 **뜻 갈래 지시**는 앞에 유지: `같은 top이 '으뜸가는'을 뜻한다.`
   - 표지는 `—`가 아니라 **`처럼,`** (— 는 관용어구로 오독됨)

5. **해설(c) 하나로 통합** ★2026-07-12 변경
   - 옛 `v`(변별) 필드를 c로 흡수하고 폐지. **강사가 필요한 것을 그때그때 설명하는 자리**다.
     예문 들고, 문법 짚고, 헷갈리는 것 갈라주고 — 원래 하나다.
   - 함정·혼동은 **`[주의!]` 표지**로 문장 안에 표시한다.
     `목적어를 눕혀 놓는 타동사. [주의!] lie(눕다)와 최악의 혼동 짝이다 — …`
   - 필드를 나누면 오분류가 생긴다 (pay for/pay, believe/believe in처럼
     **같은 단어의 용법 차이**를 '변별'에 잘못 넣는 사고가 실제로 났다).
   - **데이터는 한 덩어리, 배치는 게임/docx가 결정.**
     예문식 알림·문법 설명·주의 표지를 어떻게 쪼개 보여줄지는 렌더 단계의 몫이다.

6. **해설은 정보가 있을 때만**
   - ❌ 동어반복 ("white → 흰색의", "star → 하늘의 별") — 배포분 71건 + 미검수 148건 삭제
   - ✅ 위상·범위·제약·뉘앙스 ("wish → 이루기 힘든 걸 바라다", "amount → 셀 수 없는 것의 양")
   - 예문을 해설에서 되풀이하지 않는다.
   - **동어반복 요약 금지.** 예문 세 개로 대비를 보여줬으면 "정리하면 A는 ~, B는 ~"를 덧붙이지 않는다.
   - **빼는 것도 완성도다.**

7. **발음은 IPA로** — 한글 표기 금지 ("리드/레드" ✗ → /riːd/ /red/ ✓)
   - 강세 억양차(party 미·영)는 무시. **뜻·품사가 바뀌는 강세만** 다룸(record, increase)
   - 해설의 IPA는 **대조 목적일 때만** (use /juːz/ vs /juːs/)

8. **학생에게 내부 사정을 보이지 않는다**
   - 태그 = 우리 설계 메모. **학생판 비표시.**
   - "N세트", "회수" 같은 내부 용어는 본문에 쓰지 않음. **단어 이름만** 남긴다.
   - 개인화 코멘트 금지. 매체 의존 표현 금지("아래" → "다음" — 게임에선 다음 카드가 됨)

9. **검수 시 세트 간 정합도 확인** (변별 상호참조: see↔meet, big/large/great)

| 쌍 | 차이 |

| group / class | group=아무 무리 / class=배우는 반 |
| live / stay | live=오래 삶(거주) / stay=잠시 머묾 |
| place / point | place=넓이 있는 장소 / point=하나의 점 |
